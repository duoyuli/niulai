# 决策记录索引

> 上级索引：[工程文档](../index.md)

## 范围

本分类保存架构决策记录（ADR）：做出某个选择的背景、取舍和后果。当前的系统行为以其他分类的文档为准；被取代的决策保留原文，并标明取代它的决策。
