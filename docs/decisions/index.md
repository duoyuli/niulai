## 范围

本分类保存架构决策记录（ADR）：背景、取舍和后果。当前系统行为以架构、领域、接口和运维文档为准；ADR 主要回答「为什么这样做」。已经被取代的决策保留在历史区，不能作为部署或开发依据。
