# ADR：采用等比复权作为指标口径

- 状态：已采纳（accepted），2026-10-15。决策第 1 条中「保存每日累计复权因子」的存储方式，以及后果第 2 条「新 K 线要重算因子才出现在复权视图中」，已被 [ADR：等比复权因子按区间存储](adj_factor_segments.md) 取代，计算口径不变。
- 相关文档：[复权](../domains/price_adjustment.md)、[均线与交叉信号](../domains/ma_signals.md)。

## 背景

均线等技术指标必须在复权价上计算，否则除权除息造成的价格断崖会产生假的交叉信号。全市场全历史实测：直接用未复权原价计算 MA15/MA30，与等比复权相比约有 2.4 万次交叉日期不同。

供应商同花顺使用减法复权（「精确复权」），本项目已经能精确复现它（误差 1e-11）。用户没有金融背景，要求参考业内最通用的做法。

## 决策

1. 计算指标、判断信号、计算收益率，一律使用**等比复权**，与 Tushare 等主流量化数据服务的做法一致：保存原价和每日累计复权因子，前复权价 = 原价 × 因子 / 最新因子，后复权价 = 原价 × 因子。
2. 同花顺的减法复权保留为 `*_ths` 视图，只用于和同花顺软件对数、在 K 线图上显示与同花顺一致的价格。
3. 回测中的成交价、分红现金和送股数量使用原价加公司行动事件。

## 取舍

| 方面 | 等比复权 | 同花顺减法复权 |
| --- | --- | --- |
| 负价 | 不会出现 | 全市场 168 只股票、约 9 万根 K 线的前复权最低价不大于 0 |
| 涨跌幅 | 每天都与真实情况一致 | 早期价格越低，偏差越大 |
| 前复权与后复权的信号 | 只差常数倍，交叉日期完全相同（19.96 万次金叉，差异为 0） | 不是常数倍，交叉日期可能不同 |
| 与同花顺软件显示的数字 | 不同 | 相同 |
| 除权当天与交易所口径 | 交易所把参考价四舍五入到分，低价股在除权当天可能差约 0.1% | — |

两种口径相比，有 1,059 次金叉日期不同，涉及 577 只股票。

## 后果

- 因子从本库第一根 K 线（最早 2005 年）开始累计，更早的事件不计入，所以老股票的后复权价与供应商「从上市日起」的后复权价相差常数倍。涨跌幅和信号不受影响。
- 新的 K 线或公司行动写入后，要重算因子才能出现在 `qfq`、`hfq` 视图中。目前在运行结束后全量重算，约 40 秒。
- 判断交叉时必须加容差（相对差 1e-9），否则快线和慢线完全相等时，浮点误差会产生假交叉。
