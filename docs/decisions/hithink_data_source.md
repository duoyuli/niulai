# ADR：采用同花顺金融数据服务，以 REST 为主

- 状态：已采纳（accepted），2026-10-15。取代 [ADR：使用同花顺 iFinD](ifind_data_source.md)。后果第 1 条中「限速必须跨进程共享」已被 [ADR：限速在进程内](in_process_rate_limit.md) 取代。
- 相关文档：[同花顺接口](../interfaces/hithink_api.md)、[数据目录](../interfaces/dataset_catalog.md)、[复权](../domains/price_adjustment.md)、[行情数据规则](../domains/market_data_rules.md)。

## 背景

项目需要把 A 股的全部历史行情同步到本地 PostgreSQL，之后每个交易日 T+1 增量。用户持有同花顺金融数据服务（HiThink Financial API，`https://fuyao.aicubes.cn`）的免费 API Key。项目要部署到服务器，用户倾向全部走 REST，不在本地用 DuckDB 等工具处理导出文件。

供应商同时提供两种取数方式：逐只证券的 REST 接口，以及全市场导出（先取预签名链接，再下载 Parquet）。

## 决策

1. 数据源采用同花顺金融数据服务，使用免费 Key。
2. 行情和其他数据一律走 REST。首次全量按证券 × 10 年窗口请求；每日 T+1 用全市场快照写入当天日线，每周用历史接口从游标往前重叠 10 天校对。
3. **例外**：公司行动用全市场导出文件（`a_share.corp_action_dump`）。逐只 REST 接口不返回配股字段，全市场 987 次配股会算错复权。导出接口本身也是普通 HTTP 请求，服务器上可以直接调用，Parquet 由后端的 `parquet` 库读取。
4. 数据库只保存未复权原价和公司行动事件，复权价由本地计算，口径见 [ADR：采用等比复权](equal_ratio_adjustment.md)。

## 取舍

- **REST 与导出文件**：导出文件 3 次请求就能拿到全市场 10 年日线，但最多只有 10 年，而且只有日线和公司行动两类。REST 能取到 2005 年起的日线和其他所有数据，可以用同一套同步框架处理。实测 REST 全量回补只需 43 分钟，代价可以接受。
- **快照与历史接口**：快照 28 页就能取完当天全市场，但成交量和成交额只有约 9 位有效数字；历史接口精确，但每天要请求约 5,580 次。选择快照保证当晚可用，每周用历史接口覆盖。
- **已知缺口**（接受，记录在案）：
  - 没有退市股票，回测有幸存者偏差；
  - 没有停牌记录和历史 ST；
  - 没有股本数据，流通市值从集合竞价终态每天积累；
  - 个股日线从 2005 年起，指数日线从 2022 年起。

## 后果

- 首次回补和每日同步都依赖一个供应商的 API Key，限速必须跨进程共享，见 [限速与单一执行进程](../architecture/sync_pipeline.md#rate_limit)。
- 只有当前值的数据（估值、指数成分、异动原因等）必须从开始采集那天起每天积累。
- 以后如果要补退市股票，需要另找数据源（例如 BaoStock）。
- 同步层直接使用 `HithinkClient`，不保留只有一个实现的客户端 trait（2026-10-23 架构评审后删除）：端点名、分页、错误码和导出文件格式本来就在 `datasets.yaml`、`sync::fetch` 和 `sync::sinks` 里，换数据源时要连同它们一起评估，只抽象传输层省不了多少事。

## 验证记录（2026-10-15）

| 项目 | 结果 |
| --- | --- |
| REST 全量拉取 | 5,580 只股票，9,504 次请求，3 个并发用时 43 分钟；1,518 万根日线（2005-01-04 至今）。8 次请求出错（4 次传输中断、4 次返回非 JSON），重试后全部成功 |
| REST 与全市场导出文件逐行对比 | 重叠的 968 万行，开高低收、成交量、成交额全部一致。补拉漏掉的 2,863 个上市首日后，两者逐行完全一致 |
| 本地复权价与 REST `adjust=forward/backward` 逐日对比 | 8 只覆盖分红、送转、配股、同日多事件的样本股，开高低收的最大绝对误差在 1e-11 以内 |
| 收盘快照与当日日线对比（270 只） | 开高低收全部一致；成交量有 18 只、成交额有 239 只存在 1e-8 量级的差异 |
| 快照前收与上一日收盘价不一致的股票 | 4 只，都在当天除权，说明快照前收是交易所调整过的值 |
| 1,104 万行日线入库与查询 | 入库 52 秒，占用 1.8 GB；全市场最新一日 MA15/MA30 扫描 2.1 秒；单只股票全历史 14 毫秒 |
