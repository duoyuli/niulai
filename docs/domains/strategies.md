# 选股策略与诊断

本文说明技术指标和信号的口径、选股策略的定义与判断规则、内置模板、每日巡检、个股诊断和市场环境。策略只用三个概念：**指标**（每天一个数，例如 20 日均线）、**信号**（某天发生的一件事或所处的状态，例如「5 日均线上穿 20 日均线」）、**策略**（股票池加一组条件）。为什么这样设计，见 [ADR：选股策略是 JSON 定义](../decisions/strategy_design.md)。计算在 `backend/src/analysis/`（`indicators.rs`、`signals.rs`、`strategy.rs`、`screener.rs`、`diagnosis.rs`、`market.rs`），接口见 [REST API](../interfaces/rest_api.md#endpoints)，策略的回测见 [回测](backtest.md)。

## 章节导航

- [指标](#indicators)：指标的价格口径、公式和周期范围。
- [涨跌停](#limits)：涨跌停价的推算规则，涨停、跌停、炸板信号依赖它。

<a id="indicators"></a>
## 指标

指标在一只股票按日期升序的日线上计算，返回与日线等长的序列，数据不够算出的位置为空（NaN），比较时视为不满足。

- **价格口径：** 开高低收一律用等比前复权价，成交量和成交额用原值，见 [复权](price_adjustment.md)。除权除息日不会产生假涨跌和假信号。
- **百分数单位：** 单位为 `pct` 的指标直接是百分数，5 表示 5%（不是 0.05）。策略条件里的数值、止损止盈百分比都用这个单位。
- **停牌：** 停牌日没有日线，不计入任何窗口，「N 日」都指 N 个有日线的交易日。

| 指标 | 口径 |
| --- | --- |
| 涨跌幅、振幅 | 相对前一根日线的前复权收盘价；振幅 = (最高 − 最低) / 前收盘 |
| `ma`、`ema` | 简单均线与 [均线口径](ma_signals.md#ma_definition) 相同；指数均线 α = 2 / (n + 1)，第一天取当天收盘 |
| `ma_gap` | 收盘价相对 n 日均线的偏离（%） |
| MACD | DIF = EMA12 − EMA26，DEA = DIF 的 EMA9，柱 = 2 × (DIF − DEA) |
| RSI | 与通达信、同花顺口径一致：上涨幅度和涨跌幅度分别做平滑移动平均 SMA(X, n, 1)，前 n 根为空 |
| KDJ | 参数 9、3、3：RSV 用 9 日最高最低价，K、D 是 SMA(X, 3, 1)，初值 50，J = 3K − 2D |
| 布林带 | 中轨是 20 日均线，上下轨是中轨 ± 2 倍 20 日样本标准差 |
| ATR | 真实波幅的 n 日简单平均；`atr_pct` 是 ATR / 收盘价（%） |
| `vol_ratio` | 当天成交量 ÷ 前 n 天（不含当天）的平均成交量 |
| `momentum` | 相对 n 个交易日前收盘价的涨跌（%） |
| `high_n`、`low_n` | 最近 n 根（含当天）的最高价、最低价 |
| `pct_from_high`、`pct_from_low` | 收盘价相对最近 n 根最高、最低**收盘价**的距离（%） |

带周期的指标在目录（`GET /api/v1/strategies/catalog`）里给出默认值和范围，周期最大 250。

<a id="limits"></a>
## 涨跌停

供应商不提供每日涨跌停价，按交易所规则推算：

- **涨跌幅限制：** 北交所 30%，科创板 20%，创业板 2020-08-24 起 20%（之前按主板），主板 10%，主板 ST 5%。ST 按**现在的简称**判断，历史上戴帽摘帽的时段可能判错。
- **基准价：** 前一交易日收盘价，除权日用除权参考价。前复权价之比消去了除权：基准 = 今天的原价收盘 × 昨天前复权收盘 / 今天前复权收盘。涨停价 = 基准 × (1 + 限制)，四舍五入到分。
- **判断：** 收盘价不低于涨停价减 0.005 元为涨停，跌停同理；盘中最高价达到涨停价、收盘没有封住为炸板。
- **新股：** 本库第一根日线就是上市首日（相差不超过 3 天）时，前 5 根日线不判断。
- 回测判断一字板（买不进、卖不出）不用这套规则，用「最高价等于最低价且相对前收盘上涨或下跌」，见 [回测](backtest.md#rules)。

<a id="signals"></a>
## 信号

信号目录在 `signals.rs` 的 `CATALOG` 中，共 25 个，分为均线、MACD、超买超卖、突破、量能、K 线形态、涨跌停七组。每个信号有名称模板（参数代入后就是白话名称）、偏多或偏空（前端用红色或绿色显示）、类型和参数范围。

- **事件**（`event`）：某一天发生的事，例如金叉、放量、创新高。条件里可以要求「当天出现」或「最近 N 个交易日内出现过」（N 不超过 20）。
- **状态**（`state`）：某一天所处的状态，只有均线多头排列和空头排列两个，按当天判断。
- **交叉：** 「A 上穿 B」与均线金叉同一套规则和容差，见 [交叉判定](ma_signals.md#cross_rule)；数据不足的开头部分不参与。「上穿某个水平」（MACD 上穿零轴、RSI 上穿 30）是前一天在水平下方、当天在上方。
- **新高新低：** 收盘价高于（低于）之前 n 根的所有收盘价，不含当天。
- **放量：** 当天成交量是前 5 根平均的 `ratio` 倍以上。
- **长下影线：** 下影线不短于实体的 2 倍，且不短于股价的 3%。

每个信号还给出需要多少根预热日线（例如 MACD 120 根），巡检和回测按它决定读多少历史。

<a id="definition"></a>
## 策略定义

策略是一段 JSON（`Definition`），保存在 `app.strategy.definition`，不是代码：

```json
{
  "universe": {"boards": [], "exclude_st": true, "min_price": 2, "min_amount": 50000000, "min_listed_days": 60, "sector": null},
  "all": [{"kind": "signal", "signal": "ma_cross_up", "params": {"fast": 5, "slow": 20}, "within_days": 1}],
  "any": [],
  "exit": {"any": [{"kind": "signal", "signal": "price_cross_below_ma", "params": {"n": 20}}], "stop_loss_pct": 8, "take_profit_pct": null, "max_hold_days": 20},
  "sort": {"by": {"id": "amount"}, "desc": true},
  "limit": 50
}
```

- **股票池**（`universe`）：先排除不想看的股票。板块为空表示全部；价格用未复权收盘价，成交额用当天原值。「上市满 N 个交易日」按本地读入的日线根数判断，所以巡检会读至少 N 根，N 不超过 500。`sector` 是 [强势板块过滤](#market)。
- **条件：** `all` 中每一条都要满足；`any` 不为空时至少满足一条。条件有两种：
  - `signal`：信号在当天，或最近 `within_days` 个交易日内出现过。参数缺省时用目录中的默认值。
  - `compare`：左边是一个指标，右边是一个数值或另一个指标，运算符是 `>`、`>=`、`<`、`<=`。任一边为空（数据不足）时不满足。
- **卖出规则**（`exit`）：只在回测时使用，见 [回测](backtest.md#rules)。
- **排序：** 按某个指标排序后保留前 `limit` 只（1 到 200），排序值为空的排在最后。
- **校验：** 至少一个条件，买入条件和卖出条件各最多 10 个，参数在目录范围内，均线类信号要求快线短于慢线。不通过时接口返回 400 和原因；JSON 结构本身不对（例如未知的信号）返回 422。
- **白话说明：** 每条条件都能转换成一句话，例如「当天出现「5 日均线上穿 20 日均线」」「最近 3 个交易日内出现过「放量（2 倍以上）」」「当天处于「均线多头排列（5 > 20 > 60）」」「收盘价高于 60 日均线」。接口在 `explained` 中返回整个策略的说明，巡检结果的 `reasons` 是每只股票命中的条件。

<a id="templates"></a>
## 内置模板

`strategy.rs` 的 `templates()` 提供 10 个模板：均线金叉、均线多头、回踩 20 日均线、放量突破、创 60 日新高、MACD 金叉、超跌反弹、布林带突破、低位放量、强势股回调。新建策略时可以从模板开始改。

- 模板的股票池都是默认值：排除 ST、股价不低于 2 元、成交额不低于 5,000 万元、上市满 60 个交易日。
- 模板默认的卖出规则：收盘跌破 20 日均线，或亏损 8%，或持有满 20 个交易日，满足任一条就卖。
- 服务第一次启动时，把 10 个模板各复制为一个普通策略并开启巡检，让「选股」页一开始就有结果。只做一次（`app.setting` 中的 `strategies_seeded`），用户删掉的不会再出现。之后修改模板不影响已复制的策略。

<a id="screening"></a>
## 每日巡检

巡检用开启了巡检（`screening = true`）的全部策略，在一个交易日上把全市场过一遍，保存结果。

- **时机：** 每次同步运行结束、后处理返回「有新数据」时自动执行，见 [运行后的处理](../architecture/sync_pipeline.md#postprocess)；也可以用 `POST /api/v1/screening/run` 手动执行（可以只执行一个策略、指定交易日）。
- **范围：** 当天有日线的股票（停牌股不参与），按股票逐只读入最近一段日线，在每只股票上依次判断所有策略，所以同时运行多个策略与运行一个的耗时差不多。读入的根数是所有策略中最大的预热根数加 5。
- **耗时：** 本地实测，10 个策略、5,566 只股票约 1 到 2 秒。
- **保存：** 每个 (策略, 交易日) 一行 `app.screen_run`，记录参与的股票数和满足条件的数量；排序后保留的股票写入 `app.screen_hit`，包括名次、命中的条件和当天的价格、成交额。同一策略同一天再次巡检时覆盖。
- **新入选：** 与该策略在更早交易日上的最近一次巡检比较，上次不在结果中的标为新入选（`is_new`），上次在、这次不在的作为 `removed` 返回。第一次巡检没有可比较的对象，不标新入选。比较的是排序截断后保存的股票。
- **强势板块：** 有 `sector` 条件的策略，先按当天的板块排名算出允许的股票集合，见 [市场环境](#market)。
- 修改策略后，已保存的历史结果不重算。

<a id="diagnosis"></a>
## 个股诊断

`GET /api/v1/securities/{thscode}/diagnosis` 用最近 300 根日线，对最新交易日给出四个维度的一句话结论，每个维度偏强、中性或偏弱：

| 维度 | 偏强 | 偏弱 | 其余 |
| --- | --- | --- | --- |
| 趋势 | 5、20、60 日均线多头排列 | 空头排列 | 均线交织；不足 60 根时不判断 |
| 动量 | 近 20 个交易日涨 10% 以上 | 跌 10% 以上 | 补充说明 RSI(14) 是否超买（≥ 70）或超卖（≤ 30） |
| 量能 | 量比（5 日）≥ 1.5 且收涨 | 量比 ≥ 1.5 且收跌 | 量比 ≤ 0.7 为缩量，其余为平稳 |
| 位置 | 处在 60 日最高最低价区间的 80% 以上 | 20% 以下 | 区间中部 |

- **最近信号：** 最近 20 个交易日内出现过的事件类信号（每个信号用默认参数），新的在前，最多 15 个。自选股列表的「最近信号」用同一个函数，范围是最近 5 个交易日。
- **关键价位：** 60 日最高最低价、20 日和 60 日均线、布林带上下轨，都是前复权价，在当前收盘价上方的是压力，下方的是支撑。
- **符合的策略：** 用全部已保存的策略（不论是否开启巡检）判断当天是否满足股票池和条件；强势板块过滤不参与。
- 诊断只描述已经发生的走势，不预测涨跌。

<a id="market"></a>
## 市场环境

- **市场概况**（`GET /api/v1/market/overview`）：当天有日线的股票中，上涨、下跌、平盘家数（按前复权涨跌幅），涨停跌停数（按 [涨跌停](#limits) 推算），涨跌幅中位数，收盘站上 20 日均线的比例（只统计够算 20 日均线的股票）。
- **板块强弱**（`GET /api/v1/market/sectors`）：同花顺行业（`industry`）或概念（`cn_concept`）指数在最近 `days` 个交易日的涨跌幅排名，用 `mkt.index_bar_1d` 的收盘价。板块指数日线从 2022 年起才有。
- **强势板块过滤：** 策略的 `universe.sector` 取排名前 `top_pct`% 的板块（至少 1 个），只保留它们的**当前成分股**（`ref.index_member` 中 `valid_to` 为空的记录）。成分股没有历史，所以这个过滤只在巡检和预览中生效，回测中不生效。
