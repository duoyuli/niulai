# 选股策略与诊断

本文说明技术指标和信号的口径、条件和策略的定义、买卖点、每日巡检、信号的过去表现、个股诊断和市场环境。用户只需要理解四个词：**指标**（每天一个数，例如 20 日均线）、**条件**（一句是或否的判断，例如「收盘价上穿 60 日均线」）、**信号**（起了名字的条件，内置或自己定义）、**策略**（买入条件加卖出规则）。为什么这样设计，见 [ADR：选股策略是 JSON 定义](../decisions/strategy_design.md) 和 [ADR：信号是起了名字的条件](../decisions/custom_signals.md)。计算在 `backend/src/analysis/`（`indicators.rs`、`limit_pool.rs`、`signals.rs`、`strategy.rs`、`signal_lib.rs`、`points.rs`、`screener.rs`、`signal_stats.rs`、`diagnosis.rs`、`market.rs`），接口见 [REST API](../interfaces/rest_api.md#endpoints)，策略的回测见 [回测](backtest.md)。

<a id="indicators"></a>
## 指标

指标在一只股票按日期升序的日线上计算，返回与日线等长的序列，数据不够算出的位置为空（NaN），比较时视为不满足。

- **价格口径：** 开高低收一律用等比前复权价，成交量和成交额用原值，见 [复权](price_adjustment.md)。除权除息日不会产生假涨跌和假信号。
- **百分数单位：** 单位为 `pct` 的指标直接是百分数，5 表示 5%（不是 0.05）。策略条件里的数值、止损止盈百分比都用这个单位。
- **停牌：** 停牌日没有日线，不计入任何窗口，「N 日」都指 N 个有日线的交易日。

| 指标 | 口径 |
| --- | --- |
| 涨跌幅、振幅 | 相对前一根日线的前复权收盘价；振幅 = (最高 − 最低) / 前收盘 |
| `ma`、`ema` | 简单均线与 [均线口径](ma_signals.md#ma_definition) 相同；指数均线 α = 2 / (n + 1)，第一天取当天收盘 |
| `ma_gap` | 收盘价相对 n 日均线的偏离（%） |
| MACD | DIF = EMA12 − EMA26，DEA = DIF 的 EMA9，柱 = 2 × (DIF − DEA) |
| RSI | 与通达信、同花顺口径一致：上涨幅度和涨跌幅度分别做平滑移动平均 SMA(X, n, 1)，前 n 根为空 |
| KDJ | 参数 9、3、3：RSV 用 9 日最高最低价，K、D 是 SMA(X, 3, 1)，初值 50，J = 3K − 2D |
| 布林带 | 中轨是 20 日均线，上下轨是中轨 ± 2 倍 20 日样本标准差 |
| ATR | 真实波幅的 n 日简单平均；`atr_pct` 是 ATR / 收盘价（%） |
| `vol_ratio` | 当天成交量 ÷ 前 n 天（不含当天）的平均成交量 |
| `momentum` | 相对 n 个交易日前收盘价的涨跌（%） |
| `high_n`、`low_n` | 最近 n 根（含当天）的最高价、最低价 |
| `pct_from_high`、`pct_from_low` | 收盘价相对最近 n 根最高、最低**收盘价**的距离（%） |
| `prev_high_close`、`prev_low_close` | 之前 n 根（**不含当天**）的最高、最低收盘价；「创 60 日新高」就是收盘价高于 `prev_high_close(60)` |
| DMI：`plus_di`、`minus_di`、`adx` | 与通达信、同花顺一致：MTR、DMP、DMM 是最近 n 天真实波幅、上升动向、下降动向之和（上升动向 = 今天最高 − 昨天最高，大于 0 且大于下降动向时取它，否则 0），+DI = DMP × 100 ÷ MTR，−DI 同理；ADX 是 \|−DI − +DI\| ÷ (−DI + +DI) × 100 的 6 日均线 |
| `supertrend` | 与 TradingView 的 `ta.supertrend` 一致：中价 ± 3 × ATR(n)，这里的 ATR 用 Wilder 平滑（不是上面 `atr` 的简单平均）；下轨只升不降、上轨只降不升（昨收越过时重置），收盘越过当前的线就翻转；上升趋势取下轨，下降趋势取上轨，开始时按下降趋势。结果依赖之前的状态，预热读 4n + 60 根 |
| `cci` | 与通达信、同花顺一致：典型价 = (最高 + 最低 + 收盘) ÷ 3，CCI = (典型价 − n 日均值) ÷ (0.015 × n 日平均绝对偏差)，偏差为 0 时取 0 |
| `boll_width` | 布林带宽度：(上轨 − 下轨) ÷ 中轨 × 100 |
| `ma_spread` | 均线粘合度：5、10、20、60 日均线中最高与最低之差 ÷ 收盘价 × 100 |

带周期的指标在目录（`GET /api/v1/strategies/catalog`）里给出默认值和范围，周期最大 250。每个指标有三段说明：`description` 说是什么，`usage` 说怎么看，`formula` 说怎么算（用了哪些数据、公式和固定参数），单元测试检查每个指标都写了。`GET /api/v1/indicators` 在此之外给出常用写法（可以直接拿去新建信号的条件）和被哪些信号、策略用到。

<a id="limits"></a>
## 涨跌停

涨跌停有「以供应商名单为准」和「按交易所规则自算」两套口径，合并在一处（`analysis::indicators::Frame::limits`），下面的信号、每日巡检、市场概况都用合并后的结果。

**以供应商的涨跌停池为准（优先）：**

- 涨停看 `special.limit_up_pool`（2020-07-22 起，每个交易日齐全，`payload.continue_day_cnt` 是连板数）；跌停、炸板看 `special.limit_down_pool`、`special.limit_break_pool`（都只有 2025-10-16 起）。
- 日期在池的覆盖范围内、且不是北交所的股票，**在名单里就是涨停（跌停、炸板），不在名单里就不是**。连板数直接用供应商的值，所以数据起点就是第 5 板的股票，也能满足「连续 3 个涨停」。
- 跌停、炸板还要求这一天出现在涨停池里：涨停池每天都有数据，可以当作权威交易日历。池缺一天的数据时，不会把当天所有股票都判成没有跌停、没有炸板，而是回退自算。
- 池里没有北交所（`.BJ` 0 行），北交所始终回退自算。
- 为什么以池为准、两条分界线，见 [ADR：涨跌停以供应商的权威名单为准](../decisions/authoritative_limits.md)。

**按交易所规则自算（池没有覆盖的日期）：**

- **涨跌幅限制：** 北交所 30%，科创板 20%，创业板 2020-08-24 起 20%（之前按主板），主板 10%，主板 ST 5%。ST 按**现在的简称**判断，历史上戴帽摘帽的时段可能判错。这条规则也解释不了规则本身的变化：供应商涨停池的数据显示 **2026-07-06 起主板 ST 的涨跌幅限制从 5% 变成 10%**，自算仍按 5%，所以有池的日期必须用池。
- **基准价：** 前一交易日收盘价，除权日用除权参考价。前复权价之比消去了除权：基准 = 今天的原价收盘 × 昨天前复权收盘 / 今天前复权收盘。涨停价 = 基准 × (1 + 限制)，四舍五入到分。
- **判断：** 收盘价不低于涨停价减 0.005 元为涨停，跌停同理；盘中最高价达到涨停价、收盘没有封住为炸板。
- **新股：** 本库第一根日线就是上市首日（相差不超过 3 天）时，前 5 根日线不判断。这一条对两套口径都生效。
- 回测判断一字板（买不进、卖不出）不用这套规则，用「最高价等于最低价且相对前收盘上涨或下跌」，见 [回测](backtest.md#rules)。

数据起点处（例如 K 线只读了最近 300 根）如果第一根之前就在涨停，自算从第一根重新数会是「第 1 板」；有权威池的日期用供应商的连板数，不会截断。最近几天池还没同步到的时候，日期超出池的 `max(obs_date)`，自动回退自算。

<a id="signals"></a>
## 信号

信号是起了名字的条件（`SignalDef`）：几条条件，全部满足或任一满足。信号分内置和自定义两种，用法相同。

- **内置信号：** `signals.rs` 的 `CATALOG` 中共 56 个，分为均线、MACD、超买超卖、趋势强度、背离、突破、量能、K 线形态、涨跌停九组。每个有名称模板（参数代入后就是白话名称）、类型、参数范围，以及 `description`、`usage` 两段说明。其中 37 个由 `signals::definition` 用条件写出，参数代入条件里，例如「均线交叉」是「`ma(fast)` 上穿 `ma(slow)`」，「创 60 日新高」是「收盘价高于 `prev_high_close(60)`」，「连续 3 天上涨」是「涨跌幅高于 0，连续 3 个交易日」。最早的 19 个改写前后的结果逐位一致，单元测试用旧实现对比；之后加的用单元测试和直接按规则算的结果对比。
- **偏多、偏空、中性：** 偏多（红色向上）常被看作走强，偏空（绿色向下）常被看作走弱，中性（橙色圆点）本身不说明方向：十字星、缩量、趋势明确（ADX 高，可能是涨也可能是跌）。中性信号不列在个股诊断和自选股的「最近信号」里，见 [个股诊断](#diagnosis)。自定义信号只有偏多和偏空，复制中性的内置信号时先按偏多。
- **特殊信号：** 19 个依赖前一天的 K 线、K 线形状、高低点或涨跌停价，写不成「指标 + 比较」，规则见 [特殊信号](#special_signals)。可以在策略里用，不能复制修改。
- **不看未来：** 任何信号在某一天的结果只取决于这一天及以前的日线。单元测试对每个内置信号截掉之后的日线重算，结果必须不变；背离要等低点确认后才出现，就是为了满足这一条，否则回测会偷看未来。
- **自定义信号：** 保存在 `app.signal`，可以新建、复制内置信号后修改（`based_on` 记录来源）、改名、删除。名称 1 到 30 个字，条件最多 10 条。自定义信号只能由指标比较和内置信号组成，**不能引用别的自定义信号**，任何信号最多两层。有策略在用时不能删除（返回 409 和这些策略的名称）。修改后，用到它的策略下一次巡检起按新定义判断。
- **加载：** 判断策略、预览、回测、诊断前，`signal_lib::load` 读出全部自定义信号，放进定义的 `lib`；条件 `my_signal` 按编号到这里取定义。
- **事件和状态：** 事件（`event`）是某一天发生的事，例如均线交叉、放量；状态（`state`）是持续成立的情况，例如多头排列。自定义信号含上穿、下穿或事件类内置信号时算事件，否则算状态。白话里事件写「出现」，状态写「处于」。
- **交叉：** 「A 上穿 B」与均线交叉同一套规则和容差，见 [交叉判定](ma_signals.md#cross_rule)；数据不足的开头部分不参与。「上穿某个数」（MACD 上穿零轴、RSI 上穿 30）是前一天不高于这个数、当天高于。
- **放量：** 当天成交量是前 5 根平均的 `ratio` 倍以上。**长下影线：** 下影线不短于实体的 2 倍，且不短于股价的 3%。

每个信号还给出需要多少根预热日线（例如 MACD 120 根），巡检和回测按它决定读多少历史。`GET /api/v1/signals` 列出内置和自定义信号，每个附带定义的白话、用到的指标和被哪些策略用到。

<a id="special_signals"></a>
## 特殊信号

逻辑在 `signals::special`，规则的白话由 `special_rule` 给出，显示在信号详情页。价格都是前复权价。

- **K 线形态：**
  - 向上跳空：当天最低价高于前一天最高价；向下跳空：当天最高价低于前一天最低价。
  - 长下影线、长上影线：影线不短于实体的 2 倍，且不短于收盘价的 3%。
  - 十字星：实体不超过当天最高与最低之差的 10%，上下都有影线。
  - 看涨吞没：前一天收阴、当天收阳，当天开盘不高于前一天收盘、收盘不低于前一天开盘，且实体更长；看跌吞没相反。
  - 早晨之星：第一天收阴、实体不小于股价的 2%；第二天实体不超过第一天的 1/3，且整个实体不高于第一天收盘；第三天收阳，收盘不低于第一天实体的中点。黄昏之星相反。
- **背离**（MACD 用 DIF，RSI 用 RSI(14)）：
  - 低点：第 j 天的收盘价比前 3 天都低、不高于后 3 天（并列时取最早的一天）。要等后 3 天走完才能确认，所以信号出在第 j + 3 天。高点相反。
  - 底背离：一个低点比上一个低点（相隔不超过 60 根日线）更低，而指标在这两天的值后一个更高。MACD 底背离还要求后一个 DIF 在零轴下方。顶背离相反，MACD 顶背离要求 DIF 在零轴上方。
  - 高低点只看收盘价，两侧天数（3）和最大间隔（60）是固定参数，见 `PIVOT_SIDE`、`DIVERGENCE_MAX_GAP`。
- **均线粘合后发散：** 前 10 个交易日里至少 8 天均线粘合度（`ma_spread`）不超过 2%，当天超过 3%（前一天还不超过），且收盘价在四条均线上方（向上发散）或下方（向下发散）。
- **涨跌停：** 涨停、跌停、炸板按 [涨跌停](#limits) 判断：有权威池的日期以供应商的名单为准，池没有覆盖的日期按交易所规则推算；连续 N 个涨停用供应商的连板数，没有池时是连续 N 天收盘涨停。

<a id="definition"></a>
## 策略定义

策略是一段 JSON（`Definition`），保存在 `app.strategy.definition`，不是代码：

```json
{
  "universe": {"boards": [], "exclude_st": true, "min_price": 2, "min_amount": 50000000, "min_listed_days": 60, "sector": null},
  "all": [{"kind": "signal", "signal": "ma_cross_up", "params": {"fast": 5, "slow": 20}, "within_days": 1}],
  "any": [],
  "exit": {"any": [{"kind": "signal", "signal": "price_cross_below_ma", "params": {"n": 20}}], "stop_loss_pct": 8, "take_profit_pct": null, "max_hold_days": 20},
  "sort": {"by": {"id": "amount"}, "desc": true},
  "limit": 50
}
```

- **股票池**（`universe`）：先排除不想看的股票。板块为空表示全部；价格用未复权收盘价，成交额用当天原值。「上市满 N 个交易日」按本地读入的日线根数判断，所以巡检会读至少 N 根，N 不超过 500。`sector` 是 [强势板块过滤](#market)。
- **条件：** `all` 中每一条都要满足；`any` 不为空时至少满足一条。只有一层「全部 / 任一」，不能嵌套。条件有三种：
  - `signal`：出现一个内置信号。参数缺省时用目录中的默认值。
  - `my_signal`：出现一个自定义信号，按 `signal_id` 引用。
  - `compare`：左边是一个指标，右边是一个数或另一个指标，比较是 `>` 高于、`>=` 不低于、`<` 低于、`<=` 不高于、`crosses_above` 上穿、`crosses_below` 下穿。任一边为空（数据不足）时不满足。
- **时间范围：** 每种条件都可以加：默认看当天；`within_days` 大于 1 表示最近 N 个交易日内有一天满足；`streak_days` 大于 1 表示连续 N 个交易日都满足。两者只能设一个，N 不超过 20。
- **卖出规则**（`exit`）：买入后满足任意一条就卖出：`any` 中的卖出条件、止损、止盈、最多持有天数。巡检用它算 [买卖点](#points)，回测也用它，见 [回测](backtest.md#rules)。
- **排序：** 按某个指标排序后保留前 `limit` 只（1 到 200），排序值为空的排在最后。
- **校验：** 至少一个条件，买入条件和卖出条件各最多 10 个，参数在目录范围内，均线类信号要求快线短于慢线，引用的自定义信号要存在。不通过时接口返回 400 和原因；JSON 结构本身不对（例如未知的信号）返回 422。
- **白话说明：** 每条条件都能转换成一句话，例如「当天出现「5 日均线上穿 20 日均线」」「最近 3 个交易日内出现过「放量（2 倍以上）」」「连续 3 个交易日收盘价高于 20 日均线」「收盘价上穿 60 日均线」。前端编辑时用同样的写法实时显示（`describeCondition`）。接口在 `explained` 中返回整个策略的说明，巡检结果的 `reasons` 是每只股票命中的条件。

<a id="templates"></a>
## 内置模板

`strategy.rs` 的 `templates()` 提供 16 个模板：均线交叉（15 日 / 30 日）、均线交叉（5 日 / 20 日）、均线多头、回踩 20 日均线、放量突破、创 60 日新高、MACD 金叉、超跌反弹、布林带突破、低位放量、强势股回调、MACD 底背离、Supertrend 趋势跟随、趋势确认的均线交叉（5 日 / 20 日，ADX 高于 20 且 +DI 在 −DI 上方）、缩量回踩 20 日均线。新建策略时可以从模板开始改。均线交叉（15 日 / 30 日）是个股回测默认使用的内置策略：15 日均线上穿 30 日均线买入，下穿时卖出，不额外设置止损、止盈和最长持有天数。

- 模板的股票池都是默认值：排除 ST、股价不低于 2 元、成交额不低于 5,000 万元、上市满 60 个交易日。
- 模板默认的卖出规则：收盘跌破 20 日均线，或亏损 8%，或持有满 20 个交易日，满足任一条就卖。Supertrend 趋势跟随例外：Supertrend 翻空或亏损 10% 时卖，不限持有天数。
- **内置策略**：每个模板在 `app.strategy` 中有一行（`builtin_key` 是模板的 key），启动时按模板内容同步（`screener::sync_builtin_strategies`），只读、不能删除、总是参加巡检，只能改「是否在首页展示」；账户的 [调仓建议](accounts.md#rules) 默认参考全部参加巡检的策略，内置策略保证总有一批不会被改坏的。想改就「复制一份改」，从模板新建一个普通策略。还没有内置行时，先接管内容和模板完全一样、由这个模板创建的普通策略（以前第一次启动时由模板复制出来、没改过的），避免同一个策略出现两份；改过的保持为普通策略。模板删掉后对应的行变回普通策略。

<a id="points"></a>
## 买卖点

`points::run` 在一只股票上从某一天起空仓开始，逐日计算，不涉及资金和仓位：

- **买点：** 空仓时收盘满足买入条件（含股票池）、并且没有同时满足卖出条件，就是买点，下一个交易日开盘买入。持有中再满足不算新的买点。
- **卖点：** 持有中收盘满足任一卖出规则就是卖点，下一个交易日开盘卖出。几条同时满足时按卖出条件、止损、止盈、持有到期的顺序取第一个作为原因，卖出条件的原因写成命中那条的白话（例如「当天出现「收盘跌破 20 日均线」」）。止损止盈按收盘价相对买入价（前复权）判断。
- **一字板：** 开盘一字涨停（最高价等于最低价且高开）买不进、一字跌停卖不出时，顺延到下一个交易日，直到成交；顺延期间出现卖出条件会取消没成交的买入，持有中重新满足买入条件、当天又没有卖出理由会取消没成交的卖出。
- **收益：** 按前复权价计算，含分红送转，不扣费用；还没卖出的按最新收盘价。
- **最后一天的状态：** 今天是买点、今天是卖点、持有中或空仓。

每日巡检和个股 K 线上的买卖点（`GET /api/v1/securities/{thscode}/strategy-points`，默认从 3 年前算起）都用它，和单只股票回测的买卖规则相同（单元测试用随机日线逐笔对比），只是不算资金和手数，见 [回测](backtest.md#rules)。同一个策略在不同页面上的起点、板块过滤和费用口径不同，数字会不一样，对照表见 [各路径的买卖点口径](backtest.md#calibers)。

<a id="screening"></a>
## 每日巡检

巡检用开启了巡检（`screening = true`）的全部策略，在一个交易日上把全市场过一遍，保存最新买点、最新卖点和持有中。

- **时机：** 每次同步运行结束、后处理返回「有新数据」时自动执行，见 [运行后的处理](../architecture/sync_pipeline.md#postprocess)；也可以用 `POST /api/v1/screening/run` 手动执行（可以只执行一个策略、指定交易日）。
- **范围：** 当天有日线的股票（停牌股不参与），按股票逐只读入最近一段日线，在每只股票上依次判断所有策略，所以同时运行多个策略与运行一个的耗时差不多。买卖点从 250 个交易日（`POINT_DAYS`，约一年）前空仓开始推算，所以读入的根数是 250 加所有策略中最大的预热根数。
- **耗时：** 本地实测，14 个内置策略、5,566 只股票约 17 秒（debug 构建）。权威涨跌停池在巡检开始时整个窗口加载一次（约 1.9 年、3 万多行，实测约 0.3 秒），不按股票重复读取；接入前 17.4 秒，接入后 18.5–19.1 秒（debug 构建，机器负载不同会有波动）。
- **三类结果：** 按 [买卖点](#points) 推算每只股票的最后一天：最新买点按策略的排序保留前 `limit` 只；最新卖点全部保存，带原因；持有中按买入以来的涨跌从高到低最多保存 300 只。卖点和持有中带买入日、买入价、买入以来的涨跌和已持有天数。预览（`POST /strategies/preview`）只看今天是否满足买入条件，不推算买卖点、不考虑是否持有，所以可能和巡检结论不同，见 [各路径的买卖点口径](backtest.md#calibers)。
- **保存：** 每个 (策略, 交易日) 一行 `app.screen_run`，记录参与的股票数和买点数；结果写入 `app.screen_hit`，`kind` 区分 `buy`、`sell`、`holding`，卖点和持有中的数量从这里统计。同一策略同一天再次巡检时覆盖。
- **新入选：** 只对买点：与该策略在更早交易日上的最近一次巡检比较，上次不在买点中的标为新入选（`is_new`）。第一次巡检没有可比较的对象，不标新入选。
- **强势板块：** 有 `sector` 条件的策略，先按当天的板块排名算出允许的股票集合，只用于过滤买点，见 [市场环境](#market)。
- 修改策略或它用到的自定义信号后，已保存的历史结果不重算。
- **在首页展示：** 策略的 `show_on_today` 为 false 时照常巡检、可以在策略页查看结果，只是不出现在首页。用于只为测试建的策略。

<a id="signal_stats"></a>
## 信号的过去表现

`POST /api/v1/signals/stats` 统计一个信号（或还没保存的草稿定义）最近 1 到 5 年（默认 3 年）在全市场的表现，`signal_stats::compute` 逐只股票计算：

- **股票池：** 默认股票池（排除 ST、股价不低于 2 元、成交额不低于 5,000 万元、上市满 60 个交易日），每天按当天的数据判断。
- **出现：** 连续几天都满足只算第一天。
- **持有期：** 出现那天收盘到之后第 5、10、20 个交易日收盘的涨跌（前复权），给出平均、中间值和上涨比例；还没有那么多天后续数据的不计入。
- **对比：** 同一段时间、同一股票池里所有股票任意一天之后同样天数的平均涨跌和上涨比例，看这个信号是不是比随便买好。
- **最近出现：** 最近 30 次，附出现后 20 个交易日的涨跌。
- **耗时和缓存：** 3 年全市场第一次约 19 秒（debug 构建），结果按条件、自定义信号的定义和 `ops.derived_version` 中 adj_factor、limit_pool 的时间戳缓存在进程内（最多 64 条），复权价重算或权威涨跌停池有变化后失效，命中时约 20 毫秒。
- 只是统计描述，不扣费用，不代表以后，页面上写明了。

`POST /api/v1/signals/today` 用同一个股票池给出今天出现这个信号的股票（按成交额前 50 只），`POST /api/v1/securities/{thscode}/signal-days` 给出一只股票上出现的日子（连续几天只给第一天），供 K 线标记。

<a id="diagnosis"></a>
## 个股诊断

`GET /api/v1/securities/{thscode}/diagnosis` 用最近 300 根日线，对最新交易日给出四个维度的一句话结论，每个维度偏强、中性或偏弱：

| 维度 | 偏强 | 偏弱 | 其余 |
| --- | --- | --- | --- |
| 趋势 | 5、20、60 日均线多头排列 | 空头排列 | 均线交织；不足 60 根时不判断 |
| 动量 | 近 20 个交易日涨 10% 以上 | 跌 10% 以上 | 补充说明 RSI(14) 是否超买（≥ 70）或超卖（≤ 30） |
| 量能 | 量比（5 日）≥ 1.5 且收涨 | 量比 ≥ 1.5 且收跌 | 量比 ≤ 0.7 为缩量，其余为平稳 |
| 位置 | 处在 60 日最高最低价区间的 80% 以上 | 20% 以下 | 区间中部 |

- **最近信号：** 最近 20 个交易日内出现过的事件类信号（每个信号用默认参数），新的在前，最多 15 个。中性的信号（十字星、缩量）很常见、本身不说明方向，不列出。300 根日线覆盖每个信号的预热（最多的是 MACD 背离，约 190 根），单元测试检查。自选股列表的「最近信号」用同一个函数，范围是最近 5 个交易日。
- **关键价位：** 60 日最高最低价、20 日和 60 日均线、布林带上下轨，都是前复权价，在当前收盘价上方的是压力，下方的是支撑。
- **符合的策略：** 用全部已保存的策略（不论是否开启巡检）判断当天是否满足股票池和条件；强势板块过滤不参与。
- 诊断只描述已经发生的走势，不预测涨跌。

<a id="market"></a>
## 市场环境

- **市场概况**（`GET /api/v1/market/overview`）：要把全市场的日线算一遍（约 1 秒），所以结果按交易日和 `ops.derived_version` 中 adj_factor、limit_pool 的时间戳缓存在进程内，每次同步写入行情或权威涨跌停池有变化后时间戳更新、缓存失效，命中时约 5 毫秒。统计内容是当天有日线的股票中，上涨、下跌、平盘家数（按前复权涨跌幅），涨停跌停数（有权威池的日期以供应商名单为准，池没有覆盖的日期按 [涨跌停](#limits) 推算），涨跌幅中位数，收盘站上 20 日均线的比例（只统计够算 20 日均线的股票）。
- **板块强弱**（`GET /api/v1/market/sectors`）：同花顺行业（`industry`）或概念（`cn_concept`）指数在最近 `days` 个交易日的涨跌幅排名，用 `mkt.index_bar_1d` 的收盘价。板块指数日线从 2022 年起才有。
- **强势板块过滤：** 策略的 `universe.sector` 取排名前 `top_pct`% 的板块（至少 1 个），只保留它们的**当前成分股**（`ref.index_member` 中 `valid_to` 为空的记录）。成分股的变动只从开始采集那天起有记录（`valid_from`、`valid_to`），更早的没有，所以这个过滤只在巡检和预览中生效，回测中不生效。
