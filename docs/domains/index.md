# 领域文档索引

> 上级索引：[工程文档](../index.md)

## 范围

本分类记录 A 股行情数据的业务规则：除权除息与复权、时间戳与交易日、证券上市退市、快照精度、均线与交叉信号、权威涨跌停池与热点页面、选股策略与诊断，以及策略回测的规则。同步框架本身见 [架构](../architecture/index.md)，供应商接口的限制见 [接口](../interfaces/index.md)。

## 文档

- [复权](price_adjustment.md)：除权除息和复权的概念、等比复权因子的计算、同花顺减法复权、公司行动的来源与去重规则、复权视图与 API 参数。阅读时机：涉及价格、复权因子、`mkt.corp_action`、`*_qfq` / `*_hfq` 视图，或需要向非金融背景的读者解释复权。
- [行情数据规则](market_data_rules.md)：时间戳换算、交易日、上市与退市推断、ST、停牌、快照与历史接口的精度差异、数据覆盖范围。阅读时机：处理供应商时间戳、请求窗口、交易日、`ref.security`，或写入当天日线。
- [均线与交叉信号](ma_signals.md)：均线口径、交叉的判定规则与容差（所有「上穿」「下穿」都用它）、自选股诊断。阅读时机：修改 `ma.rs`、`api/watchlist.rs`，或交叉判定。新增技术指标或信号见「选股策略与诊断」。
- [今日热点](hotspots.md)：权威涨停、跌停、炸板池的数据来源和口径，`GET /market/hot` 接口，首页「今日热点」卡片和 `/hot` 页面的结构，以及数据滞后时的空态。阅读时机：修改 `api/market.rs` 的热点接口、`TodayPage.tsx` 或 `HotPage.tsx`，或解释页面上的涨停、跌停、炸板、连板数字。
- [选股策略与诊断](strategies.md)：38 个指标和 56 个信号的口径、特殊信号的规则（K 线形态、背离等）、涨跌停推算、条件和自定义信号、策略定义与 15 个模板、买卖点、每日巡检、信号的过去表现、个股诊断、市场概况与板块强弱。阅读时机：修改 `backend/src/analysis/` 中的指标、信号、策略、买卖点、巡检、诊断或市场环境，或解释为什么某只股票出现买点、卖点或没有入选。
- [账户与调仓建议](accounts.md)：账户、持仓、流水和分红送转自动记账、撤销流水与已实现盈亏、配股提醒与认购、每日净值曲线，交易规则与费用，选股和风控规则（三组参考值），每日调仓建议的生成规则和理由，策略过去表现、规则回测和建议回看。阅读时机：修改 `backend/src/account/`、`backend/src/advice/`、`api/accounts.rs` 或账户页面，或解释某条建议为什么出现、为什么没出现。
- [回测](backtest.md)：单只股票的选股策略和全市场组合回测的交易规则、分红送转与交易成本、指标含义、各路径的买卖点口径对照、近似和没有模拟的情况。阅读时机：修改 `backend/src/analysis/backtest.rs`、`portfolio.rs`，解释回测结果或页面之间数字为什么不一样，或扩展回测。
