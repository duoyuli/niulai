# 领域文档索引

> 上级索引：[工程文档](../index.md)

## 范围

本分类记录 A 股行情数据的业务规则：除权除息与复权、时间戳与交易日、证券上市退市、快照精度、均线与交叉信号，以及策略回测的规则。同步框架本身见 [架构](../architecture/index.md)，供应商接口的限制见 [接口](../interfaces/index.md)。

## 文档

- [复权](price_adjustment.md)：除权除息和复权的概念、等比复权因子的计算、同花顺减法复权、公司行动的来源与去重规则、复权视图与 API 参数。阅读时机：涉及价格、复权因子、`mkt.corp_action`、`*_qfq` / `*_hfq` 视图，或需要向非金融背景的读者解释复权。
- [行情数据规则](market_data_rules.md)：时间戳换算、交易日、上市与退市推断、ST、停牌、快照与历史接口的精度差异、数据覆盖范围。阅读时机：处理供应商时间戳、请求窗口、交易日、`ref.security`，或写入当天日线。
- [均线与交叉信号](ma_signals.md)：均线口径、金叉死叉的判定规则与容差、全市场扫描和自选股诊断的范围。阅读时机：修改 `backend/src/analysis/` 中的均线、信号和扫描，或新增技术指标。
- [回测](backtest.md)：均线交叉策略的交易规则、分红送转与交易成本、指标含义、没有模拟的情况。阅读时机：修改 `backend/src/analysis/backtest.rs`，解释回测结果，或扩展回测。
