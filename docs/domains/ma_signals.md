# 均线与交叉信号

本文说明均线的计算口径、金叉和死叉的判定规则，以及全市场扫描和自选股诊断的范围。价格口径的背景见 [复权](price_adjustment.md)，接口参数见 [REST API](../interfaces/rest_api.md#endpoints)。计算在 `backend/src/analysis/`（`ma.rs` 是均线和交叉，`scan.rs` 是全市场扫描），接口在 `backend/src/api/`；单只股票、全市场扫描、自选股诊断和 [回测](backtest.md) 共用同一套计算。为什么不在 SQL 中计算，见 [ADR：指标在 Rust 中计算](../decisions/indicator_compute.md)。

<a id="ma_definition"></a>
## 均线口径

- 价格：等比前复权收盘价（`mkt.v_stock_bar_qfq.close`）。等比前复权和等比后复权只差一个常数倍，信号结果相同，见 [等比复权因子](price_adjustment.md#equal_ratio_factor)。
- 均线：简单移动平均。N 日均线是当天及之前共 N 根 K 线收盘价的平均值；停牌日没有 K 线，不计入。按滑动窗口加补偿求和计算，与逐个相加求平均的相对差小于 1e-13。
- 周期：快线 `fast` 默认 15，慢线 `slow` 默认 30。两者都必须在 2 到 250 之间，且 `fast < slow`。
- 只输出 K 线数量达到 `slow` 根之后的点；上市初期不足 `slow` 根时，没有均线和信号。
- 查询指定 `start` 时，均线仍然用 `start` 之前的历史计算，只是不返回 `start` 之前的点；指定 `end` 时，只用 `end` 及之前的数据。

<a id="cross_rule"></a>
## 交叉判定

每天按快线和慢线的相对差确定一个状态：

```
相对差 = (快线 − 慢线) / |慢线|
相对差 >  1e-9   → 状态 +1（快线在上）
相对差 < −1e-9   → 状态 −1（快线在下）
其余              → 状态 0（视为相等）
```

信号规则：
- **金叉**（`golden`）：状态从上一个非零状态 −1 变为 +1。
- **死叉**（`death`）：状态从上一个非零状态 +1 变为 −1。
- 状态为 0 的日子不改变「上一个非零状态」，也不产生信号。例如 −1、0、+1 的序列，在 +1 那天产生金叉。

需要容差的原因：快线和慢线完全相等时（例如连续一字涨停、长时间价格不变），浮点误差会让相对差在 ±1e-16 附近来回跳，没有容差就会产生假交叉。全市场实测中，不加容差时等比前复权和等比后复权有 1,823 次交叉日期不同，全部来自这种情况；加容差后差异为 0。

<a id="market_scan"></a>
## 全市场扫描

`GET /api/v1/signals/ma-cross` 返回指定交易日发生金叉或死叉的股票，默认是本地日线的最新交易日：
- 每只股票取截至该日、往前 `(slow + 60) × 2` 个自然日内的 K 线，在这个范围内计算均线和状态，判定规则与单只股票相同。
- 只有当天有 K 线、且范围内的 K 线够算出当天慢线的股票参与扫描，响应中的 `scanned` 是参与扫描的股票数；停牌股不参与。
- 结果按 (交易日, 快线, 慢线) 缓存在进程内，复权因子重算完成后失效，见 [ADR：指标在 Rust 中计算](../decisions/indicator_compute.md)。`signal` 参数只是在缓存结果上过滤。
- 扫描只看范围内的状态。如果某只股票在范围内、当天之前的状态全部为 0（快线和慢线一直相等），上一个非零状态就落在范围之外，扫描不会判为交叉，而单只股票接口会。这种情况只出现在长期一字板或价格长期不变的股票上。

参考耗时（2026-10-16，PostgreSQL 17，约 1,500 万行日线）：全市场扫描第一次 0.33–0.49 秒，命中缓存约 2 毫秒；单只股票全历史均线 5–11 毫秒。

<a id="watchlist"></a>
## 自选股诊断

`GET /api/v1/watchlist` 对每只收藏的股票给出快速诊断，实现在 `backend/src/api/watchlist.rs`，均线用 `analysis::ma`：
- 每只股票取最近 500 根等比前复权日线（约两年），在这个范围内计算均线和状态，判定规则与单只股票相同。最近一次交叉只在这个范围内找，更早的交叉不返回。
- `change_1d`、`change_20d` 用前复权收盘价计算，除权除息日不会出现假涨跌。
- 还没有日线时 `diagnosis` 为空，不足 `slow` 根时 `diagnosis.ma` 为空。
- `recent_signals` 是最近 5 个交易日出现过的事件类信号，规则与 [个股诊断](strategies.md#diagnosis) 的最近信号相同。
