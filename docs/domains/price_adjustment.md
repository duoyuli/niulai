# 复权

<a id="concepts"></a>
## 概念

**除息**：公司给股东分现金。例如贵州茅台 2026-06-26 每股分红 28.02423 元，前一天收盘 1212.10 元。分红后股东多了现金，公司少了同样多的钱，所以交易所把当天的参考价下调为 1212.10 − 28.02423 ≈ 1184.08 元。股东的总资产不变。

**除权**：公司送股或转增股本，例如「10 送 10」。股数翻倍，公司价值不变，每股价格减半。配股（股东按比例以优惠价认购新股）也会下调参考价。

**价格断崖**：实际成交价在除权除息日会出现跳空。茅台那天收盘 1168.63 元，看起来比前一天跌了 3.6%，其实大部分是分红造成的；「10 送 10」时看起来像跌了 50%。直接用这样的价格算均线，会产生假的交叉信号。

**复权**：改写一部分价格，让断崖消失。要做两个选择：

| 选择 | 选项 | 含义 |
| --- | --- | --- |
| 以哪头为准 | 前复权 | 最新价不动，调整除权日之前的价格。同花顺软件默认显示前复权 |
| | 后复权 | 最早价不动，调整除权日及之后的价格。历史价格以后不会再变 |
| 怎么调 | 等比复权 | 按比例缩放。涨跌幅与真实情况一致，不会出现负价 |
| | 减法复权 | 按金额加减（同花顺称为「精确复权」）。早年价格可能被减成负数，涨跌幅会失真 |

本项目计算指标的标准口径是**等比复权**；同花顺的减法复权只用于对数。

<a id="raw_storage"></a>
## 保存什么

- `mkt.stock_bar_1d` 只存**未复权原价**，即每天实际成交的价格。原价一旦写入就不会因为新的除权事件而改变。
- `mkt.corp_action` 存**公司行动事件**：每股现金分红 `cash_div`（税前）、每股送转股 `bonus_ratio`、每股配股 `rights_ratio`、配股价 `rights_price`。
- 前复权价随每次新的除权事件变化，所以不落库为固定值；所有复权价都由原价和事件计算得到。

<a id="equal_ratio_factor"></a>
## 等比复权因子

计算规则（`mkt.rebuild_adj_segment`）：

```
除权参考价 = (前收 − 每股分红 + 配股比例 × 配股价) / (1 + 送转比例 + 配股比例)
当天比例   = 前收 / 除权参考价
factor    = 从本库第一根 K 线起各次比例的累乘（第一根 K 线为 1）
后复权价   = 原价 × factor
前复权价   = 原价 × factor / 最新 factor
```

细节：
- 「前收」是该股票上一根 K 线的原始收盘价。
- 事件作用在除权日当天或之后的第一根 K 线上；停牌期间跨过多个除权日时，按除权日顺序合并成一次调整。
- 除权参考价不大于 0 时，这次事件不计入。
- 没有对应 K 线的事件不计入：早于本库第一根 K 线的事件，以及已公告但尚未到除权日的事件。因此老股票的后复权价与供应商「从上市日起」的后复权价相差一个常数倍，涨跌幅和信号不受影响。
- 计算使用的事件来自视图 `mkt.adj_event_effective`，同一天多条事件时的取舍见 [公司行动规则](#corp_action_rules)。
- 交易所会把除权参考价四舍五入到分，本项目用的是不四舍五入的理论参考价。所以低价股在除权当天的涨跌幅可能与交易所口径差约 0.1%，其他日子完全一致。

因子只在除权日变化，所以按区间存储：`mkt.adj_segment` 的每一行是一只股票的一个区间 `[valid_from, valid_to)`，按除权日切分，`factor` 是这个区间的后复权因子，`qfq_factor` 是前复权因子（factor / 最新一段的 factor）。同一行还有同花顺口径的分段系数，见 [同花顺减法复权](#ths_subtractive)。从未除权的股票没有分段行，因子按 1 处理。存储方式的取舍见 [ADR：等比复权因子按区间存储](../decisions/adj_factor_segments.md)。

运行结束后，如果日线或公司行动有变化，就全量重算；长时间的回补运行中每 5 分钟也重算一次，见 [运行结束后的计算](../architecture/sync_pipeline.md#postprocess)。手动重算用 `niulai recompute`。重算在一个事务中删除再插入全部分段（约 6 万行），查询在提交前看到的是旧结果，不会被阻塞；全市场一次约 3 秒。同时只能有一次重算（事务级咨询锁），后来的那次等前一次结束。

新的一天的日线落在最后一个区间（`valid_to` 为 infinity）中，写入后立即有复权价。只有当天正好除权的股票，要等重算后前复权价才按新事件调整。

等比复权下，前复权价和后复权价只差一个常数倍，所以基于它们算出的均线交叉日期完全相同。全市场全历史实测：19.96 万次 MA15/MA30 金叉，两种口径的日期差异为 0。

<a id="ths_subtractive"></a>
## 同花顺口径

同花顺的复权是逐个除权日做仿射变换：

```
前复权：除权日之前的价格  P → (P − 每股分红 + 配股比例 × 配股价) / (1 + 送转比例 + 配股比例)
后复权：上式的逆变换，从最早的事件起依次应用
```

所以在两个除权日之间，复权价是 `a × 原价 + b`，`a` 和 `b` 是常数。`mkt.adj_segment` 按除权日分段保存这两个系数（前复权 `fwd_a`、`fwd_b`，后复权 `bwd_a`、`bwd_b`），全市场约 6.3 万段，与等比因子在同一行、同一次重算中得到，见 [等比复权因子](#equal_ratio_factor)。

与同花顺 REST 接口 `adjust=forward`、`adjust=backward` 的返回值逐日对比，8 只覆盖分红、送转、配股和同日多事件的样本股，开高低收的最大绝对误差在 1e-11 以内。

已知特点：
- 前复权价可能为负。例如宁德时代 2018-06 有两个交易日前复权收盘价为负，同花顺返回的也是负数。全市场有 168 只股票、约 9 万根 K 线的前复权最低价不大于 0。
- 前复权只计入除权日不晚于本库最新交易日的事件，与同花顺接口的行为一致。

<a id="corp_action_rules"></a>
## 公司行动规则

**来源**：默认使用 `a_share.corp_action_dump`（全市场导出文件），它包含配股字段。逐只 REST 接口 `a_share.corp_action` 不返回配股字段，全市场有 987 次配股会因此算错，所以默认关闭。两者不要同时开启。如果同时写入，REST 数据只覆盖 `source = rest` 的行，不会覆盖导出文件写入的完整数据。

**同一除权日多条事件**：供应商数据中同一股票同一天可能有多行（2026-10-15 的数据里有 3 例），`seq` 保留源数据中的顺序。逐日对比表明，同花顺的复权价只采用同一天的最后一条，`mkt.adj_event_effective` 按这个规则取舍，等比复权和同花顺口径都使用它。原始的每一行仍然保留在 `mkt.corp_action`。这一规则来自对样本的观察，供应商没有文档说明。

**已公告未除权的事件**：导出文件里包含除权日在未来的事件（2026-10-15 有 113 条）。它们照常写入 `mkt.corp_action`，但在除权日到来、出现对应 K 线之前不参与计算。

**除权日换算**：事件的 `ex_date_ms` 用 `ops.ms_to_cn_date` 换算为日期，1986–1991 年夏令时期间的事件也能得到正确日期，见 [时间戳](market_data_rules.md#timestamps)。

<a id="adjust_views"></a>
## 复权视图与 API 参数

| API 参数 `adjust` | 视图 / 表 | 用途 |
| --- | --- | --- |
| `none` | `mkt.stock_bar_1d` | 未复权原价；回测中的成交价、分红和送股核算 |
| `qfq`（默认） | `mkt.v_stock_bar_qfq` | 等比前复权；指标、信号、收益率 |
| `hfq` | `mkt.v_stock_bar_hfq` | 等比后复权；与 `qfq` 的信号结果相同 |
| `qfq_ths` | `mkt.v_stock_bar_qfq_ths` | 同花顺减法前复权；与同花顺软件对数、K 线图显示 |
| `hfq_ths` | `mkt.v_stock_bar_hfq_ths` | 同花顺减法后复权；与同花顺接口对数 |

所有复权视图都按日期区间关联 `mkt.adj_segment`，每根 K 线都有复权价；没有分段行的股票按原价返回。接口的其他约定见 [REST API](../interfaces/rest_api.md)。
