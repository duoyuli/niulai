# 回测

本文说明均线交叉策略回测的交易规则、分红送转与交易成本的处理、各项指标的含义，以及目前没有模拟的情况。均线和交叉的判定见 [均线与交叉信号](ma_signals.md)，价格口径见 [复权](price_adjustment.md)。实现在 `backend/src/analysis/backtest.rs`，接口是 `GET /api/v1/backtest/ma-cross`（见 [REST API](../interfaces/rest_api.md#endpoints)）。

## 章节导航

- [交易规则](#rules)：修改买卖时机、仓位、涨跌停处理，或想知道某笔交易为什么在那天成交。
- [分红送转与交易成本](#costs)：核对盈亏、手续费、分红金额。
- [指标](#metrics)：解释收益、回撤、胜率等数字。
- [没有模拟的情况](#limits)：评估回测结果的可信度，或准备扩展回测。

<a id="rules"></a>
## 交易规则

策略只有一种：单只股票，只做多，金叉买入、死叉卖出。

- **信号：** 用等比前复权收盘价计算快慢线，规则与单只股票的均线接口相同。`start` 之前的历史也参与计算，所以回测第一天就有完整的均线。
- **成交时机：** 收盘后才知道当天是否发生交叉，所以在下一个交易日按开盘价成交，不使用当天还不知道的信息。A 股当天买入、次日才能卖出（T+1），这个规则自然满足。
- **仓位：** 空仓时遇到金叉，用全部现金按每手 100 股买入，买入金额加佣金不超过现金；不够一手时放弃这次信号，计入 `skipped_buys`。持仓时遇到死叉，全部卖出。
- **开始时的状态：** 回测第一天空仓。即使当时快线已经在慢线上方，也要等到下一次金叉才买入。
- **一字涨跌停：** 成交日全天只有一个价格（最高价等于最低价）并且高于前一天收盘时，视为一字涨停，买不进；低于前一天收盘时视为一字跌停，卖不出。订单顺延到下一个交易日，直到成交或被反向信号取消，顺延次数计入 `deferred_orders`。比较用前复权价，除权日不会误判。
- **反向信号：** 还没成交的买单遇到死叉、还没成交的卖单遇到金叉时，订单取消。
- **期末：** 最后一天仍持有的交易不卖出，按最后收盘价计算市值，不扣卖出费用。它出现在交易记录里（`exit_date` 为空），但不计入已卖出的笔数和胜率。
- **停牌：** 停牌日没有 K 线，不能成交，订单等到复牌第一天。

<a id="costs"></a>
## 分红送转与交易成本

成交价和持仓市值用未复权价，分红送转按公司行动事件处理，这是 [ADR：采用等比复权](../decisions/equal_ratio_adjustment.md) 决策第 3 条的要求。事件来自 `mkt.adj_event_effective`，同一天多条时的取舍与复权计算相同。

- **除权日：** 在开盘前处理。前一天收盘时持有的股票享有分红送转：除权日当天开盘卖出也能拿到，当天开盘买入的拿不到。停牌期间的除权日，在复牌第一天处理。
- **现金分红：** 按税前金额计入现金，不自动再买入。实际到账要扣红利税，税率与持有时间有关（持有超过 1 年免税），回测没有扣。
- **送转股：** 股数按比例增加，不足 1 股的部分舍去。
- **配股：** 不参与认购。持有期间遇到配股，除权后市值会下降，与真实情况下放弃配股一致。
- **佣金：** 买卖都收，默认万分之 2.5，单笔不足 5 元按 5 元收。
- **印花税：** 只在卖出时收，默认千分之 0.5（2023-08-28 起的税率）。更早的区间实际税率是千分之 1，需要时用参数 `stamp_tax_rate` 调整。
- **没有计入：** 过户费、滑点（成交价与开盘价的差）、资金利息。

<a id="metrics"></a>
## 指标

| 字段 | 含义 |
| --- | --- |
| `final_equity`、`total_return` | 最后一天收盘时的账户总值（现金加持仓市值）和相对初始资金的收益 |
| `annual_return` | 年化收益，按自然日折算：(1 + 收益)^(365.25 / 天数) − 1。区间不足 90 个自然日时为空 |
| `max_drawdown` | 最大回撤：按每天收盘的账户总值，从此前最高点下跌的最大幅度 |
| `benchmark_*` | 买入持有基准：同样的本金在区间第一天开盘全部买入并持有到最后。可以买零股、不计费用，分红送转与策略的处理相同 |
| `closed_trades`、`wins`、`win_rate` | 已卖出的笔数、其中盈利的笔数和比例。盈亏 = 卖出所得 + 分红 − 买入成本 |
| `avg_bars_held` | 已卖出交易的平均持有交易日数 |
| `exposure` | 收盘时持仓的交易日占全部交易日的比例 |
| `fees`、`dividends` | 佣金加印花税合计、收到的现金分红合计（税前） |

`equity` 每个交易日一个点，同时给出策略和基准的账户总值，前端用它画收益曲线。

<a id="limits"></a>
## 没有模拟的情况

- 只看一字板判断能否成交。盘中涨停封板、跌停排队、开盘价附近成交量不足等情况都按开盘价成交。
- 策略是满仓进出，没有止损、分批建仓、多只股票组合。资金较少而股价很高时（例如十万元买贵州茅台），大部分现金买不满一手，这部分现金不产生收益，策略会因此落后于可以买零股的基准。
- 只用本地已有的日线：回补尚未完成的股票，区间会比预期短。退市股票的日线到退市为止，期末仍持有时按最后一天的收盘价计算市值。
- 回测不保存结果，每次按参数重新计算（单只股票十年约 30 毫秒）。
