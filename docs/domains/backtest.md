# 回测

本文说明回测的交易规则、分红送转与交易成本的处理、各项指标的含义，以及目前没有模拟的情况。回测有三种：单只股票的均线交叉、单只股票的选股策略（`backend/src/analysis/backtest.rs`），以及全市场组合（`backend/src/analysis/portfolio.rs`）。接口是 `GET /api/v1/backtest/ma-cross`、`/backtest/strategy`、`/backtest/portfolio`（见 [REST API](../interfaces/rest_api.md#endpoints)）。均线和交叉的判定见 [均线与交叉信号](ma_signals.md)，策略的条件见 [选股策略与诊断](strategies.md#definition)，价格口径见 [复权](price_adjustment.md)。

## 章节导航

- [交易规则](#rules)：修改单只股票回测的买卖时机、卖出规则、仓位、涨跌停处理，或想知道某笔交易为什么在那天成交。
- [分红送转与交易成本](#costs)：核对盈亏、手续费、分红金额。
- [指标](#metrics)：解释收益、回撤、胜率等数字。
- [全市场组合回测](#portfolio)：修改 `portfolio.rs`，或解释组合回测与单只股票回测的差别。
- [没有模拟的情况](#limits)：评估回测结果的可信度，或准备扩展回测。

<a id="rules"></a>
## 交易规则

单只股票只做多。买入和卖出信号有两种来源：

- **均线交叉：** 金叉买入、死叉卖出。用等比前复权收盘价计算快慢线，规则与单只股票的均线接口相同。
- **选股策略：** 某天满足策略的股票池和买入条件就是买入信号（强势板块过滤不参与）。持仓期间每天收盘后按策略的卖出规则检查，依次看卖出条件、止损、止盈、最长持有天数，满足一条就卖出，交易记录的 `exit_reason` 记下是哪一条（`signal`、`stop_loss`、`take_profit`、`max_hold`）。止损止盈按前复权收盘价相对前复权买入价计算，含分红送转；持有天数从买入当天算起。卖出规则一条都没有时，买入后一直持有到期末。

以下规则两种来源相同：

- **历史：** `start` 之前的历史也参与计算，所以回测第一天就有完整的指标。
- **成交时机：** 收盘后才知道当天是否发生交叉，所以在下一个交易日按开盘价成交，不使用当天还不知道的信息。A 股当天买入、次日才能卖出（T+1），这个规则自然满足。
- **仓位：** 空仓时遇到金叉，用全部现金按每手 100 股买入，买入金额加佣金不超过现金；不够一手时放弃这次信号，计入 `skipped_buys`。持仓时遇到死叉，全部卖出。
- **开始时的状态：** 回测第一天空仓。即使当时快线已经在慢线上方，也要等到下一次金叉才买入。
- **一字涨跌停：** 成交日全天只有一个价格（最高价等于最低价）并且高于前一天收盘时，视为一字涨停，买不进；低于前一天收盘时视为一字跌停，卖不出。订单顺延到下一个交易日，直到成交或被反向信号取消，顺延次数计入 `deferred_orders`。比较用前复权价，除权日不会误判。
- **反向信号：** 还没成交的买单遇到卖出信号时取消。持仓期间每天收盘后重新检查卖出规则：仍满足任一条时继续卖出；都不满足、又出现买入信号时，取消还没成交的卖单。
- **期末：** 最后一天仍持有的交易不卖出，按最后收盘价计算市值，不扣卖出费用。它出现在交易记录里（`exit_date` 为空），但不计入已卖出的笔数和胜率。
- **停牌：** 停牌日没有 K 线，不能成交，订单等到复牌第一天。

<a id="costs"></a>
## 分红送转与交易成本

成交价和持仓市值用未复权价，分红送转按公司行动事件处理，这是 [ADR：采用等比复权](../decisions/equal_ratio_adjustment.md) 决策第 3 条的要求。事件来自 `mkt.adj_event_effective`，同一天多条时的取舍与复权计算相同。

- **除权日：** 在开盘前处理。前一天收盘时持有的股票享有分红送转：除权日当天开盘卖出也能拿到，当天开盘买入的拿不到。停牌期间的除权日，在复牌第一天处理。
- **现金分红：** 按税前金额计入现金，不自动再买入。实际到账要扣红利税，税率与持有时间有关（持有超过 1 年免税），回测没有扣。
- **送转股：** 股数按比例增加，不足 1 股的部分舍去。
- **配股：** 不参与认购。持有期间遇到配股，除权后市值会下降，与真实情况下放弃配股一致。
- **佣金：** 买卖都收，默认万分之 2.5，单笔不足 5 元按 5 元收。
- **印花税：** 只在卖出时收，默认千分之 0.5（2023-08-28 起的税率）。更早的区间实际税率是千分之 1，需要时用参数 `stamp_tax_rate` 调整。
- **没有计入：** 过户费、滑点（成交价与开盘价的差）、资金利息。

<a id="metrics"></a>
## 指标

| 字段 | 含义 |
| --- | --- |
| `final_equity`、`total_return` | 最后一天收盘时的账户总值（现金加持仓市值）和相对初始资金的收益 |
| `annual_return` | 年化收益，按自然日折算：(1 + 收益)^(365.25 / 天数) − 1。区间不足 90 个自然日时为空 |
| `max_drawdown` | 最大回撤：按每天收盘的账户总值，从此前最高点下跌的最大幅度 |
| `benchmark_*` | 买入持有基准：同样的本金在区间第一天开盘全部买入并持有到最后。可以买零股、不计费用，分红送转与策略的处理相同 |
| `closed_trades`、`wins`、`win_rate` | 已卖出的笔数、其中盈利的笔数和比例。盈亏 = 卖出所得 + 分红 − 买入成本 |
| `payoff_ratio` | 盈亏比：盈利交易的平均盈利 ÷ 亏损交易的平均亏损（取绝对值）。单只股票回测按盈亏金额，组合回测按收益率（每笔投入的金额不同）；没有盈利或没有亏损的交易时为空 |
| `avg_bars_held` | 已卖出交易的平均持有交易日数 |
| `exposure` | 收盘时持仓的交易日占全部交易日的比例 |
| `fees`、`dividends` | 佣金加印花税合计、收到的现金分红合计（税前） |

`equity` 每个交易日一个点，同时给出策略和基准的账户总值，前端用它画收益曲线。

<a id="portfolio"></a>
## 全市场组合回测

模拟每天收盘后用一个策略在全市场选股、第二天买入，账户最多同时持有 `max_positions` 只（1 到 20，默认 5）。区间最长 5 年，默认结束日前 3 年。

- **候选交易：** 先逐只股票找出区间内每个满足股票池和买入条件的信号日，按卖出规则（与 [单只股票](#rules) 相同）算出对应的一笔交易：信号日下一个交易日开盘买入，触发卖出规则的下一个交易日开盘卖出。买入日开盘一字涨停时放弃这个信号；卖出日开盘一字跌停时顺延。
- **账户：** 按交易日推进。每天开盘先卖出到期的持仓，再买入当天的候选：同一天的候选按策略的排序规则排好，已经持有的股票不重复买，仓位已满时放弃（计入 `skipped_full`）。每买一只，投入「现金 ÷ 空余仓位数」。收盘按前复权收盘价计算持仓市值，停牌的股票用最近一个收盘价。
- **基准：** 同样本金买入沪深 300 指数，本地没有它的日线时用上证指数，不计分红。本地指数日线从 2022 年起才有：区间开头 10 天内没有指数日线时不给基准。
- **近似：** 为了让几千只股票、几年的日线在几秒内算完（3 年约 6 秒、235 MB 内存），组合回测与单只股票回测有几处不同：
  - 成交价和市值用等比前复权价，相当于现金分红自动再投资、送转已计入价格，不单独处理公司行动。这偏离了 [ADR：采用等比复权](../decisions/equal_ratio_adjustment.md) 决策第 3 条，原因见 [ADR：选股策略是 JSON 定义](../decisions/strategy_design.md)。交易记录里的买入价、卖出价是未复权开盘价，只用于展示。
  - 允许买零股，不按一手 100 股取整。
  - ST 按现在的简称判断（与选股相同）。
  - 强势板块过滤不生效：板块成分股没有历史。
  - 佣金和印花税按成交金额照常扣。
- **结果：** 汇总指标的含义与单只股票相同，另有 `signals`（候选交易数）、`avg_positions`（平均每天持有几只）。交易记录按买入日期倒序，最多返回 500 笔；期末仍持有的按最后收盘价计算，不扣卖出费用。

<a id="limits"></a>
## 没有模拟的情况

- 只看一字板判断能否成交。盘中涨停封板、跌停排队、开盘价附近成交量不足等情况都按开盘价成交。
- 单只股票回测是满仓进出，没有分批建仓。资金较少而股价很高时（例如十万元买贵州茅台），大部分现金买不满一手，这部分现金不产生收益，策略会因此落后于可以买零股的基准。
- 只用本地已有的日线：回补尚未完成的股票，区间会比预期短。开始采集之后退市的股票，日线到退市为止，期末仍持有时按最后一天的收盘价计算市值；代码表不含已退市证券，开始采集之前就退市的股票本地没有，回测有幸存者偏差，结果偏乐观。
- 回测不保存结果，每次按参数重新计算（单只股票十年约 30 毫秒，全市场 3 年约 6 秒）。
