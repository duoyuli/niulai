- 发版和升级流程：
  1. 等 `main` 上该提交的 CI 通过（`gh run list`、`gh run watch <id> --exit-status`）。
  2. 打标签 `vYYYY.MM.DD.N`（同一天递增 N），push 标签，等标签的 CI 构建完镜像（约 8 分钟）。
  3. 服务器网络慢、偶尔失败：先在服务器上 `sudo docker pull -q ghcr.io/duoyuli/niulai:<版本>`，失败就重试。
  4. 登录后 `POST /api/v1/system/upgrade` `{"version":"<版本>"}`，轮询 `GET /api/v1/system/version` 直到 `current` 是新版本且 `upgrade.state` 为 `done`；中途服务重启会暂时连不上、登录会失效，重新登录继续。
