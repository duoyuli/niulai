### 1.8 交叉判定的统一规则

所有「A 上穿 B」类信号共用 `ma.rs` 的 `cross_signals` 函数：

```
相对差 = (A − B) / |B|
相对差 >  1e-9  → 状态 +1（A 在上）
相对差 < −1e-9  → 状态 −1（A 在下）
其余             → 状态 0（视为相等，不产生信号也不改变上一个非零状态）
```

金叉 = 状态从上一个非零状态 −1 变为 +1；死叉相反。容差 1e-9 消除浮点误差导致的假交叉（全市场实测：不加容差时前后复权有 1,823 次交叉日期不同，加容差后差异为 0）。

## 二、项目已有指标清单

指标是信号的输入。项目已实现的指标（`backend/src/analysis/indicators.rs`）：

| 分类 | 指标 | 口径 |
|---|---|---|
| 均线 | MA（简单均线） | Kahan 补偿求和，停牌日不计入 |
| 均线 | EMA（指数均线） | α = 2 / (n + 1)，第一天取当天收盘 |
| 均线 | `ma_gap`（均线偏离） | (收盘 − MA) / MA × 100% |
| MACD | DIF、DEA、柱 | DIF = EMA12 − EMA26，DEA = DIF 的 EMA9，柱 = 2 × (DIF − DEA) |
| KDJ | K、D、J | 参数 9/3/3，RSV 用 9 日最高最低价，K、D 是 SMA(X, 3, 1)，初值 50，J = 3K − 2D |
| RSI | RSI | 与通达信、同花顺口径一致：SMA(X, n, 1)，前 n 根为空 |
| 布林带 | 中轨、上轨、下轨 | 中轨 = 20 日 MA，上下轨 = 中轨 ± 2 倍 20 日样本标准差 |
| 波动率 | ATR、ATR% | 真实波幅的 n 日简单平均；ATR% = ATR / 收盘价 |
| 量能 | `vol_ratio`（量比） | 当天成交量 ÷ 前 n 天平均 |
| 动量 | 涨跌幅、振幅、`momentum` | 涨跌幅相对前一根前复权收盘；振幅 = (最高 − 最低) / 前收盘；momentum = 相对 n 日前涨跌（%） |
| 位置 | `high_n`、`low_n` | 最近 n 根（含当天）的最高价、最低价 |
| 位置 | `pct_from_high`、`pct_from_low` | 收盘价相对最近 n 根最高/最低收盘价的距离（%） |

### 4.2 业内常见但项目未覆盖的信号

#### 🔴 高价值缺口（建议优先补充）

**（1）MACD 底背离 / 顶背离**

- 所属平台：通达信 ✅、同花顺 ✅、东方财富 ✅、TradingView ✅
- 规则：底背离——价格创 N 日新低，但 MACD 的 DIF 没有创新低（谷值抬高）；顶背离相反。
- 具体判定：
  - 找出价格的局部低点（谷）和 DIF 的局部低点，比较最近两个谷。
  - 价格的后一个谷比前一个低，DIF 的后一个谷比前一个高，则为底背离。
  - 「局部低点」的定义需要明确：常用方法是前后各 N 根 K 线都不低于该点。N 通常取 5。
  - 谷的间距不宜太近（至少 5 根）也不宜太远（通常不超过 120 根）。
- 为什么重要：A 股最经典的抄底 / 逃顶信号之一，几乎所有技术分析教程都讲。项目已有 MACD 指标但没有做背离检测。
- 实现难度：**中高**——需要可靠的局部极值检测算法，参数（极值窗口、最大间距）会影响信号质量。

**（2）RSI 底背离 / 顶背离**

- 所属平台：通达信 ✅、同花顺 ✅、TradingView ✅
- 规则：与 MACD 背离逻辑相同，把 DIF 换成 RSI(14)。
- 为什么重要：与 MACD 背离互补。RSI 背离在超跌股中经常先于 MACD 背离出现。
- 实现难度：低（复用 MACD 背离的极值检测逻辑）。

**（3）缩量**

- 所属平台：通达信 ✅、同花顺 ✅、东方财富 ✅
- 规则：当天成交量低于前 5 日平均的某个倍数（例如 0.5 倍、0.7 倍）。
- 为什么重要：项目只有「放量」没有「缩量」。缩量上涨（惜售）和缩量下跌（卖盘枯竭）都是重要信号。与放量的逻辑完全镜像，实现成本极低。
- 实现难度：**极低**——复用 `vol_ratio`，方向相反。

**（4）大阴线**

- 所属平台：通达信 ✅、同花顺 ✅、东方财富 ✅
- 规则：当天跌幅 ≥ N%，且收盘 < 开盘。
- 为什么重要：项目有「大阳线」但没有「大阴线」，不对称。大阴线是恐慌性下跌、主力出货的典型 K 线，A 股实战中经常用到。
- 实现难度：**极低**——`big_up` 的镜像。

**（5）向下跳空**

- 所属平台：通达信 ✅、同花顺 ✅、东方财富 ✅
- 规则：当天最高价 < 前一天最低价。
- 为什么重要：项目有「向上跳空」但没有「向下跳空」，不对称。向下跳空通常伴随重大利空或恐慌，是重要的空头信号。
- 实现难度：**极低**——`gap_up` 的镜像。

**（6）MACD 下穿零轴**

- 规则：DIF 由正转负。
- 为什么重要：项目有 `macd_turn_positive`（上穿零轴）但没有下穿零轴，不对称。中期由强转弱的标志。
- 实现难度：**极低**——`crossing_level` 方向相反。

**（7）均线粘合后发散**

- 所属平台：通达信 ✅（BDZQ 指标）、同花顺 ✅
- 规则：多条均线（通常 5/10/20/60 日）在极窄区间内（如最大差 / 均值 < 2%）持续 N 天后，区间突然扩大（如差距扩大到 3% 以上）。
- 为什么重要：经典的变盘信号——长期盘整中均线收敛，一旦发散意味着方向选择，且随后的趋势往往比较持续。可以同时捕捉向上和向下的突破。
- 实现难度：**中等**——需要定义「粘合」的量化标准和持续时间。

#### 🟡 中等价值（按需补充）

**（8）量价齐升**

- 规则：价格上涨 + 放量同时出现。
- 备注：可以用现有的 `volume_surge` + 涨跌幅组合实现。但作为独立信号更直观，在个股诊断中也更好展示。
- 实现难度：**极低**。

**（9）量价背离**

- 规则：价格创 N 日新高，但成交量低于前 N 日的平均成交量（或成交量的 N 日均线走低）。
- 为什么重要：上涨动能减弱的重要警告，是 OBV 要解决的核心问题的简化版。
- 实现难度：低。

**（10）连续上涨 / 连续下跌 N 天**

- 规则：连续 N 个交易日收阳线（收盘 > 开盘）或收阴线（收盘 < 开盘）。
- 备注：项目有「连续涨停」但没有「连续上涨」。连续上涨的使用场景更广。
- 实现难度：**极低**——复用 `consecutive_limit_up` 的滑动计数器逻辑。

**（11）十字星**

- 规则：实体极小（|收盘 − 开盘| / (最高 − 最低) < 某阈值，如 10%），且上下影线都不为零。
- 为什么重要：经典的犹豫信号，出现在趋势末端时常预示反转。
- 实现难度：低。

**（12）KDJ 低位金叉 / 高位死叉**

- 规则：K、D 都在 20 以下时的金叉，或都在 80 以上时的死叉。
- 为什么重要：项目有 KDJ 金叉 / 死叉，但没有区分位置。低位金叉的实战胜率远高于高位金叉。
- 实现方式：可以作为独立信号，也可以在策略条件中用 `compare`（KDJ K < 20）+ `signal`（KDJ 金叉）组合。后者已经可以表达，但用户要自己想到。作为独立信号更直观。
- 实现难度：**极低**。

**（13）吞没形态（看涨吞没 / 看跌吞没）**

- 规则：
  - 看涨吞没：前一天阴线，当天阳线，且当天实体完全包住前一天实体（当天开盘 ≤ 前一天收盘，当天收盘 ≥ 前一天开盘）。
  - 看跌吞没相反。
- 所属平台：通达信 ✅、同花顺 ✅、TradingView ✅
- 为什么重要：两根 K 线的经典反转形态，识别率高，假信号相对少。
- 实现难度：低。

**（14）早晨之星 / 黄昏之星**

- 规则：三根 K 线组合——
  - 早晨之星：大阴线 → 小实体（十字星或小阳小阴）→ 大阳线，且第三天收盘高于第一天实体的 50% 以上。
  - 黄昏之星相反。
- 所属平台：通达信 ✅、TradingView ✅
- 为什么重要：三根 K 线的经典反转形态，可靠度较高。
- 实现难度：中等——需要定义「小实体」和「大实体」的量化标准。

**（15）DMI / ADX 交叉**

- 规则：+DI 上穿 −DI（看多），−DI 上穿 +DI（看空），ADX > 25（趋势明确）。
- 前置条件：需要先实现 DMI / ADX 指标。
- 实现难度：中等。

**（16）Supertrend 翻转**

- 规则：Supertrend 线从价格上方翻到下方（看多）或反之（看空）。
- 前置条件：需要先实现 Supertrend 指标。
- 实现难度：低（项目已有 ATR，Supertrend 只需在此基础上加状态翻转）。

**（17）布林带收口 / 开口**

- 规则：布林带宽度（(上轨 − 下轨) / 中轨）从低于 N 日最低宽度回升（开口），或从高于 N 日最高宽度回落（收口）。
- 为什么重要：波动率的变化比突破上下轨更早出现，布林带收口常预示即将变盘。
- 实现难度：低。

**（18）SAR 翻转**

- 规则：抛物线 SAR 从价格上方翻到下方（看多）或反之（看空）。
- 前置条件：需要先实现 Parabolic SAR 指标。
- 实现难度：中等。

#### 🟢 低价值或高度重叠（暂不需要）

| 信号 | 不建议的原因 |
|---|---|
| WR 超买 / 超卖 | 与 KDJ（RSV）、RSI 高度重叠 |
| DMA 金叉 / 死叉 | 与 MACD 重叠 |
| TRIX 金叉 / 死叉 | 小众，太滞后 |
| PSY 超买 / 超卖 | 价值一般 |

<a id="conclusion"></a>
## 七、结论与建议

### 7.1 现状总结

项目的 25 个信号在均线、MACD 基础、KDJ、RSI、布林带、涨跌停方面覆盖度良好。涨跌停组的 4 个信号（涨停、跌停、炸板、连板）是 A 股特色，主流平台反而没有内置，属于差异化优势。

### 7.2 核心缺口

1. **背离检测整体缺失**——MACD 和 RSI 的背离是 A 股实战中使用频率最高的反转信号之一，是信号库最大的短板。
2. **趋势强度维度整体缺失**——项目能判断趋势方向（多头 / 空头排列），但不能量化趋势强度。DMI / ADX 或 Supertrend 至少应该有一个。
3. **信号不对称**——有 6 处只有「多」没有「空」的镜像，导致策略只能捕捉看多信号，不能对称地捕捉看空信号。
4. **量能信号单薄**——只有放量，缺少缩量、量价齐升、量价背离。
5. **K 线组合形态缺失**——只有单根 K 线形态，缺少两根（吞没）和三根（早晨之星 / 黄昏之星）的经典组合。

### 7.3 建议的实施路线

- **第一批（信号对称性修补，S-01 到 S-07）：** 工作量很小（每个 < 30 分钟），能立即让信号库的完整度和专业感提升一个档次。建议与重做信号一起完成。
- **第二批（背离 + 量价关系 + KDJ 位置，S-08 到 S-15）：** 需要实现局部极值检测，这是核心工作量所在。完成后信号库覆盖 A 股最主流的技术分析场景。
- **第三批（新指标 + 趋势强度，S-16 到 S-24）：** 优先做 DMI / ADX 或 Supertrend（二选一即可），填补趋势强度维度的空白。
- **第四批（K 线组合 + 布林带变化 + 均线粘合，S-25 到 S-32）：** 锦上添花，按用户反馈决定优先级。

### 7.4 重做信号时的设计建议

基于对标分析，重做信号时建议考虑以下设计点：

1. **对称性原则：** 每个偏多信号都应有对应的偏空镜像（除非在 A 股中确实没有实际意义，如「连续跌停」）。
2. **背离检测框架：** 设计一个通用的背离检测函数（输入价格序列和指标序列，输出底背离 / 顶背离事件），使其可以复用于 MACD、RSI，将来也可以扩展到 KDJ 等指标。
3. **趋势强度指标：** 至少引入一个趋势强度指标（建议 Supertrend，因为项目已有 ATR，实现成本最低且 TradingView 用户基数大）。
4. **信号参数化策略：** 对于「KDJ 低位金叉」这类「基础信号 + 位置约束」的信号，考虑是作为独立信号还是通过策略条件组合表达。独立信号对用户更友好，但会增加信号数量；组合表达更灵活，但要求用户了解指标的数值含义。
5. **预热根数管理：** 背离检测需要较长的预热（取决于极值检测的窗口和最大间距），这会影响全市场扫描的读取量和耗时。需要在实现时权衡精度和性能。
