# TSP 的信号、策略与回测：可借鉴之处

调研日期：2026-10-16。对象：[shy3130/tick-stock-panel](https://github.com/shy3130/tick-stock-panel)（TSP，MIT 许可证，约 5,900 星），核查提交 `e737db0c767bce89ef2dac89dcd988391912c05d`。方法：阅读 README、功能手册、策略文档、《操作说明书》和信号、策略、指标、监控规则的源码；没有运行它。目的：找出能让 niulai 的个股诊断更丰富、同时不增加理解成本的做法，并设计「策略 + 每日巡检」。

## 1. TSP 有什么

| 模块 | 内容 | 实现方式 |
| --- | --- | --- |
| 指标流水线 | MA5–60、EMA5–60、MACD、RSI、KDJ、布林带、ATR、年化波动率、振幅、量比、量均线、3–60 日动量、60 日新高新低、涨跌停价、连板数、换手率 | 盘后对全市场算一遍，存为一张宽表 |
| 信号库 | 20 个内置信号：突破或跌破 MA5、MA10、MA20，MA5 上穿或下穿 MA20，MA20 上穿 MA60，MACD 金叉或死叉，突破布林上轨，跌破布林下轨，60 日新高或新低，放量，涨停，跌停，炸板，跌停翘板 | 每个信号是 JSON：几个「字段 比较符 阈值或另一字段」条件的组合，每个条件可以取 N 天前的值。「今天收盘在 MA20 上方，昨天在下方」就是「突破 MA20」 |
| 策略 | 25 个示例：趋势突破、均线多头、回踩 MA20、超跌反弹、平台整理突破、放量创 60 日新高、连板、断板反包等 | 每个策略是一个 Python 文件：参数、筛选条件、评分权重、入场和出场信号、止损、最长持有天数 |
| 回测 | 个股回测、策略组合（全市场选股、最大持仓数）、多个信号自由组合 | vectorbt；T+1、手续费、滑点、止损、止盈、移动止损；指标含夏普、最大回撤、胜率、盈亏比、蒙特卡洛回撤 |
| 因子 | DSL 公式、IC 检验、多因子组合、自动挖掘 | 面向量化研究者 |
| 监控 | 9 类规则：策略结果变化、个股信号、价格、全市场异动、连板、板块等；AND / OR、冷却期、严重级别 | 命中后弹窗，推送到飞书、企业微信、邮件、Webhook |
| 个股分析 | 9 类关键价位：筹码支撑压力、成交密集区、枢轴点、前高前低、Keltner 通道、ATR 通道、缺口、斐波那契、整数关口；AI 四维分析 | 纯函数实时计算；AI 部分需要大模型 |
| 市场环境 | 情绪周期 6 阶段（冰点、启动、主升、高潮、退潮、修复），概念和行业主线排名，连板梯队，盘后 AI 复盘 | 由涨停梯队的高度、宽度、晋级率判定 |
| 其他 | 盘中分钟信号、异动监控、模拟盘、AI 生成策略、开放 API、MCP、页面插件 | — |

## 2. 为什么它的认知成本高

- **概念太多**：信号、策略、因子、评分、监控规则（9 类）、候选方案、基础参数、策略参数，相互之间还有「四条桥」。新用户要先弄清这些概念的关系才能开始用。
- **核心能力要写代码**：策略是 Python 文件，必须遵循 META、basic_filter、scoring、ENTRY_SIGNALS 等结构。不写代码的路径只有「自定义信号」，而且信号还要再组合成策略。
- **流程长**：说明书推荐的上手流程有 9 步，跨设置、数据、自选、策略、回测、因子、监控多个页面；说明书本身有 28 章、约 5 万字。
- **结果难解读**：策略结果按评分排序，评分是几个因子的加权，用户看不出某只股票为什么入选。
- **页面多**：19 个页面，外加可安装的扩展页面。

## 3. 借鉴原则

1. **只保留三个概念**：信号（某一天发生的一件事，例如「放量突破 20 日均线」）、策略（几个信号和条件的组合，例如「均线多头 + 回踩 20 日均线 + 不是 ST」）、巡检与回测（用策略每天选股；用历史检验策略）。不引入因子、评分权重和 DSL。
2. **不写代码**：信号和策略都用下拉选项组合，界面上同时显示一句白话，例如「最近 3 天内，5 日均线上穿 20 日均线」。
3. **从模板开始**：内置十个左右常用策略，每个附一句说明「它在找什么样的股票」，可以直接用，也可以复制后修改。
4. **结果说明原因**：每只入选的股票都列出命中了哪些条件，不用不透明的评分。
5. **参数少、有默认值**：每个条件最多露出一两个数字。

## 4. 可借鉴的功能

| 功能 | 借鉴什么 | 怎么简化 | 优先级 |
| --- | --- | --- | --- |
| 指标 | MA、EMA、MACD、RSI、KDJ、布林带、ATR、量比、N 日动量、N 日新高新低、振幅、涨跌停价、连板数 | 计算放在 `backend/src/analysis/`，与现有均线同一套口径（等比前复权），按需计算，不落盘宽表 | 高 |
| 信号库 | 20 个信号和「条件 + N 天前」的定义方式 | 内置约 20 个，按「趋势、突破、动量、超买超卖、量能、涨跌停」分组，每个附白话说明；首版不开放自定义信号 | 高 |
| 个股诊断 | 关键价位、多种信号 | 详情页加一张诊断卡：趋势、动量、量能、位置四个维度各一句结论；最近 20 天触发过哪些信号；当前满足哪些策略；关键价位只取前高前低、均线支撑、布林带三类 | 高 |
| 策略 | 25 个示例策略的思路 | 用 JSON 描述，不用 Python；内置 10 个左右模板 | 高 |
| 每日巡检 | 「策略结果变化」这类监控 | 每天收盘同步完成后自动运行所有开启的策略，保存当天结果，标出新入选和移出 | 高 |
| 策略回测 | 个股回测、策略组合回测，止损、止盈、最长持有天数，盈亏比 | 在现有回测引擎上把「金叉买、死叉卖」换成「策略条件买、出场条件卖」；组合回测限制最大持仓数、等权买入 | 中 |
| 市场环境 | 上涨家数、涨停跌停数、情绪阶段 | 首页一行：上涨和下跌家数、涨停和跌停数、站上 20 日均线的股票占比。情绪周期 6 阶段需要较多验证，以后再做 | 中 |
| 板块强弱 | 概念和行业主线排名 | 行业、概念按近 5 日和 20 日涨幅排名；策略可加条件「所属行业排名前 20%」 | 中 |
| 推送 | 飞书、企业微信、Webhook | 巡检结果可以推送到一个 Webhook，以后再做 | 低 |
| 不借鉴 | 因子平台与挖掘、分钟和盘中信号、模拟盘、AI 生成策略、页面插件、ETF | 认知成本高，或数据不支持：没有分钟数据；估值从 2026-10-15 才开始积累；ST 历史从开始采集时才有 | — |

## 5. 策略与每日巡检的设计

### 5.1 用户看到的流程

1. 打开「选股」页，看到策略卡片：名称、一句说明、今天入选几只、其中新入选几只。
2. 点开一个策略：今天入选的股票，每只列出命中的条件、收盘价、涨跌幅；可以收藏、看详情、回测这个策略。
3. 新建策略：选一个模板，或从空白开始。每一行条件由下拉框组成，旁边显示白话；底部实时显示「按最近一个交易日，有 N 只股票符合」。
4. 保存后默认开启巡检：每个交易日收盘同步完成后自动运行，不需要再操作。

### 5.2 策略的定义

策略是一段 JSON，由三部分组成：股票池过滤、条件（全部满足或任一满足）、排序。

```json
{
  "universe": { "boards": ["main", "chinext", "star"], "exclude_st": true, "min_price": 3, "min_amount": 100000000 },
  "all": [
    { "signal": "ma_cross_up", "params": { "fast": 5, "slow": 20 }, "within_days": 3 },
    { "indicator": "rsi14", "op": "<", "value": 70 },
    { "indicator": "close", "op": ">", "indicator_right": "ma60" }
  ],
  "sort": { "by": "amount", "desc": true },
  "limit": 50
}
```

条件只有三种：

| 种类 | 写法 | 白话 |
| --- | --- | --- |
| 信号在最近 N 天内发生过 | `signal`、`params`、`within_days` | 「最近 3 天内，5 日均线上穿 20 日均线」 |
| 指标和一个数比较 | `indicator`、`op`、`value` | 「RSI 低于 70」 |
| 两个指标比较 | `indicator`、`op`、`indicator_right` | 「收盘价在 60 日均线上方」 |

出场条件（回测用）是同样格式的另一组条件，外加止损、止盈和最长持有天数。

### 5.3 后端

- **指标与信号**：在 `backend/src/analysis/` 新增指标和信号目录。指标在前复权的开高低收和成交量序列上计算；信号由指标组合而成，和现有均线交叉一样，在 Rust 中按股票逐只计算。
- **巡检**：每日增量运行结束、复权重算之后，对最新交易日执行所有开启的策略。全市场读取最近约 300 根日线（覆盖 MA250 的预热），逐只股票计算指标、判断条件。现有全市场扫描读取约 65 万行耗时约 0.4 秒，扩大到开高低收后预计在秒级。
- **存储**：`app.strategy`（定义、是否开启巡检、是否内置模板）和 `app.screen_result`（策略、交易日、股票、命中的条件、当时的关键指标）。与前一个交易日的结果比较，得到新入选和移出。
- **接口**：策略的增删改查，按日期查结果，用当前定义试运行（返回数量和前若干只），对策略回测。

### 5.4 首批模板

| 模板 | 在找什么样的股票 |
| --- | --- |
| 均线金叉 | 短期均线刚上穿长期均线，走势开始转强 |
| 均线多头 | 5、20、60 日均线从上到下依次排列，处在上升趋势中 |
| 回踩 20 日均线 | 上升趋势中，股价回落到 20 日均线附近 |
| 放量突破 | 成交量明显放大，同时突破 20 日均线或前高 |
| 创 60 日新高 | 股价创近 3 个月新高 |
| MACD 金叉 | MACD 快线上穿慢线 |
| 超跌反弹 | 短期跌幅大、RSI 很低，当天收阳 |
| 布林带突破 | 收盘突破布林带上轨 |
| 低位放量 | 股价在 60 日低位附近，成交量放大 |
| 强势股回调 | 近 20 日涨幅居前，近 3 日小幅回调 |

### 5.5 数据限制

- 没有分钟数据，只能做日线信号和收盘后巡检。
- 换手率需要流通股本，只能从集合竞价终态的流通市值推算，而且从开始采集的那天起才有；首版不提供换手率条件。
- 涨跌停价要按板块（主板 10%、创业板和科创板 20%、北交所 30%）和是否 ST（5%）推算。ST 历史只从开始采集时才有，早年的涨跌停判断可能不准。
- 估值从 2026-10-15 起每天积累，暂时只能用最新值做过滤，不能用于历史回测。
- 没有退市股票，回测有幸存者偏差。

## 6. 建议的实施顺序

1. **指标与信号库**：新增指标和约 20 个信号；股票详情页加诊断卡；自选页显示每只股票最近的信号。
2. **策略与每日巡检**：策略定义、模板、编辑器、「选股」页、收盘后自动巡检、新入选标记。
3. **策略回测**：单只股票用任意策略回测；然后是全市场组合回测（最大持仓数、等权）。
4. **市场环境与板块强弱**：首页的市场宽度一行；行业和概念强弱排名，作为策略条件。
5. **以后再考虑**：巡检结果推送、关键价位扩展、情绪周期。
