# niulai 工程文档

> 这是 Project Doc 根索引。加载 project-doc skill 后，在本仓库的第一个任务中完整阅读本文件，再按「阅读时机」进入相关分类。已读内容按 skill 的「Reading and context reuse」规则复用；内容缺失或需要刷新时再重读。

## 文档范围

本库记录需要跨多个代码位置才能理解的工程知识：同步框架、数据库分层、前端、复权与行情规则、指标信号与策略、回测、供应商接口、REST API 与配置、部署与运维和重要决策。单个函数就能看懂的实现细节、工作进度、临时计划和调研笔记（`docs/research/`）不在本库内。代码中的 `@project-doc docs/<路径>.md#<章节 ID>` 注释指向解释该代码的章节，修改那段代码前先读对应章节。

README 是产品入口；本索引和分类文档只记录当前工程事实。`docs/research/` 中的调研笔记是过程材料，不能替代代码、测试、配置和本索引路由到的现状文档。

- [架构](architecture/index.md)：同步流水线、数据库分层和前端。阅读时机：修改同步框架、任务队列、调度、限速、`niulai serve`、表结构、写入路径或 `frontend/`。
- [领域](domains/index.md)：复权、行情数据规则、均线与交叉、选股策略与诊断、账户与调仓建议、回测。阅读时机：涉及价格、除权除息、交易日、停牌、退市、快照、指标、信号、策略、账户持仓、调仓建议或回测。
- [接口](interfaces/index.md)：同花顺接口、可同步数据目录、datasets.yaml 格式、REST API 和配置项。阅读时机：调用或新增供应商接口、增改数据集、改动对外 API 或环境变量。
